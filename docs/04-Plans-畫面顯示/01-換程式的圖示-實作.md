# 01 換程式的圖示：實作計畫

任務檔：`01-換程式的圖示.md`（同資料夾）。

## 現況

- `src-tauri/icons/` 全是 Tauri scaffold 的預設圖示：`32x32.png`、`128x128.png`、`128x128@2x.png`、`icon.ico`、`icon.icns`、`icon.png`、`Square*Logo.png`、`StoreLogo.png`。`tauri.conf.json` 的 `bundle.icon` 引用前五個。
  - `icon.ico` 是 exe、工作列、安裝檔的圖示（Windows 實際用到的）；`Square*` / `StoreLogo` 是 MSIX / 市集用；`icon.icns` 是 macOS 用（不打包 macOS，但一起產生，保持 Tauri 的慣例）。
- 網頁的 favicon：`index.html` 的 `<link rel="icon" href="/tauri.svg">`（`public/tauri.svg`）。`public/vite.svg` 沒有被引用。
- Tauri CLI 有 `tauri icon <來源>`：吃**正方形、透明背景的 PNG 或 SVG**，一次產生上面所有尺寸與 ICO / ICNS。

## 格式建議

- **來源用 SVG**（1024 × 1024 viewBox）：向量、檔案小、可以直接 diff 與修改；`tauri icon` 直接吃 SVG（resvg 轉換），不需要另外輸出 PNG。
- SVG 裡**不放文字**（`<text>` 依賴系統字型，轉換結果會因機器而異）：字母一律畫成路徑。
- 小尺寸可讀性：Windows 檔案總管與工作列會用到 16 / 24 / 32 px，所以造型要簡單、對比高、細節少；圓角方形底，四周留一點邊（陰影或其他圖示並排時不擠）。

## 設計方向（三個候選）

都用 App 選取框的靛藍色系（indigo），和畫面一致。

| 候選 | 概念 | 說明 |
|---|---|---|
| A 翻開的雜誌 | 跨頁 | 靛藍底、白色的兩頁攤開、中間書背，頁面上有標題條與圖片塊。呼應雙頁編輯與翻頁電子書 |
| B 雜誌封面 | 封面 + 刊頭 | 一本立著的雜誌封面，上方是粗的刊頭「M」，下面是封面圖，右下頁角翻起 |
| C 排版版面 | 編輯器 | 一頁版面（標題、圖片框、文字行）＋選取框的四個控制點，表示「可拖放編輯」 |

候選放在本資料夾 `icons/`（`icon-a.svg`、`icon-b.svg`、`icon-c.svg`），另附 `icons/preview.html`：每個候選以 16 / 24 / 32 / 48 / 64 / 256 px、淺色與深色底並排，方便比較小尺寸的效果。

## 步驟

1. **畫三個候選**：`icons/icon-a.svg`～`icon-c.svg` + `preview.html`，截圖確認小尺寸；交給使用者選（可以要求修改）。
2. **置換圖示**：選定的 SVG 存成 `src-tauri/app-icon.svg`（來源，進 repo）→ `npx tauri icon src-tauri/app-icon.svg` 產生 `src-tauri/icons/` 全部檔案（只保留 `bundle.icon` 用到的與 Tauri 預設會產生的；`android/`、`ios/` 不要）→ favicon 換成同一張 SVG（`public/app-icon.svg`，`index.html` 改引用），刪掉 `public/tauri.svg`、`public/vite.svg`。
3. **驗證**：`cargo check`（`icon.ico` 會被 `tauri-build` 嵌進 exe）、`npm run build`；檢查 ICO 含的尺寸；`npm run tauri dev` 看視窗 / 工作列圖示（使用者在桌面版確認）。
4. **記錄**：本計畫、`docs/progress.md`、CLAUDE.md（圖示來源與重新產生的指令）。
