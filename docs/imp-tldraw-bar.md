# 實作計畫：底部工具列（參考 tldraw）

> 任務檔：`docs/04-tldraw.md`
> 狀態：**步驟 3 已完成（2026-09-30），等使用者確認後進行步驟 4**
> 建立：2026-09-30

---

## 1. 目標

參考 tldraw，在畫布下方中央加入浮動的**底部工具列**，把最常用的功能放在手邊：

- **主工具列**：選取工具、手形工具、文字、圖形（最近用過的圖形 + `^` 展開全部圖形）、圖片。
- **動作列**（主工具列左上方的小列）：復原、重做、刪除、複製，以及 `⋮` 更多。

## 2. 參考畫面拆解

![[tldraw-toolbar.png]]

| 區塊 | tldraw 的內容 | 本專案對應 |
|---|---|---|
| 主工具列 | 選取、手形、畫筆、橡皮擦、箭頭、文字、便利貼、圖片、矩形（最近用過的圖形）、`^` | 選取、手形、文字、圖形、圖片；**畫筆 / 橡皮擦 / 箭頭 / 便利貼沒有對應的物件類型**（見第 6 節第 2 題） |
| `^` 圖形選單 | 20 種圖形的格狀選單 | 目前的矩形、圓角矩形、圓形、三角形、星形（與「元素」面板相同的清單） |
| 動作列 | 復原、重做、刪除、複製、留言、`⋮` | 復原、重做、刪除、複製、`⋮`（圖層順序等）；**複製是新動作** |
| 目前工具 | 藍底高亮 | `bg-primary`（design token；目前主題的 primary 是近黑色） |

tldraw 的核心是**工具模式**：先選工具，再到畫布上點擊或拖曳建立物件，建立後自動回到選取工具。

## 3. 現況與差異

| 項目 | 現況 | 需要的改變 |
|---|---|---|
| 新增物件 | 面板按鈕 → 加到**頁面中央**（`pageCenter`） | 工具模式下改成**在點擊位置建立**，拖曳可以直接決定大小 |
| 目前工具 | 沒有這個狀態，畫布只有「選取 / 拖曳物件」一種模式 | 新增 `tool` UI 狀態（不進復原歷史） |
| 平移畫布 | 只有捲軸與 Ctrl+滾輪縮放 | 手形工具拖曳平移；按住空白鍵暫時切換成手形（tldraw 與多數設計軟體的慣例） |
| 復原 / 重做 | 在上方系統控制列 | 移到動作列（見第 6 節第 3 題） |
| 複製物件 | 沒有 | 新增 `element/duplicate`（位移 10pt、進復原歷史），快捷鍵 Ctrl+D |
| 快捷鍵 | Delete / Ctrl+Z / Ctrl+Y / Esc / 方向鍵 | 工具快捷鍵 V（選取）、H（手形）、T（文字）、R（矩形）、O（圓形）；以 `event.code` 比對，注音輸入法下也有效 |

## 4. 設計

### 4.1 工具狀態（`lib/editor`，先做、可測試）

- `EditorState` 新增 `tool: ToolId`（UI 狀態，和 `view`、`selectedId` 一樣**不進復原歷史**）。
  - 放在 reducer 而不是 `home-page.tsx`，因為畫布、底部工具列、快捷鍵都要讀它。
- 新增 action：
  - `tool/set`：切換工具；切換時取消選取。
  - `element/duplicate`：複製選取的物件，位移 10pt，新物件成為選取物件。
- 新增 `lib/editor/tools.ts`：工具的單一資料來源（id、名稱、快捷鍵 code、圖示在 UI 端補），同 `PANEL_DEFINITIONS` 的做法。
- `ToolId`：`select`、`hand`、`text`、`shape`（搭配「目前圖形」`shapeKind`，也是按鈕上顯示的「最近用過的圖形」）。**圖片不是工具模式**：按鈕直接開選檔對話框，所以不在 `ToolId` 裡。
- 步驟 1 的實作細節：
  - `element/duplicate` 的新 id 由呼叫端產生、放在 action 裡（`newId`），reducer 保持純函式（React 開發模式會把 reducer 執行兩次）；複本插在原物件**正上方一層**，不是最上層。
  - `tool/set` 切到文字 / 圖形時取消選取，切到選取 / 手形保留選取；開啟其他專案時保留目前工具。
  - 工具快捷鍵定義在 `TOOL_SHORTCUTS`，只接受不帶修飾鍵的按鍵，所以不會和選單快捷鍵（都帶 Ctrl）衝突，測試也有檢查。

### 4.2 畫布行為（`editor-canvas.tsx`）

| 工具 | 點擊 | 拖曳 | 結束後 |
|---|---|---|---|
| 選取 | 現有行為 | 現有行為 | — |
| 手形 | — | 平移畫布（改 `scrollLeft/Top`，不 dispatch） | 保持手形 |
| 文字 | 在點擊位置建立文字並**直接進入編輯** | 拖曳寬度 = 換行寬度 | 回到選取 |
| 圖形 | 在點擊位置建立預設大小的圖形 | 拖曳框 = 圖形外框，拖曳中顯示預覽框 | 回到選取 |
| 圖片 | —（按工具列的圖片按鈕直接開選檔對話框，加到頁面中央） | — | 回到選取 |

- 拖曳建立時只在放開時 dispatch 一次 `element/add`（和「dragend 才 dispatch」原則一致），預覽框是畫布的 local state。
- 空白鍵按住 = 暫時手形，放開回到原工具；滑鼠中鍵拖曳也平移。焦點在輸入框、文字編輯中時不攔截空白鍵。
- 游標：手形 `grab` / `grabbing`，建立工具 `crosshair`。

- 步驟 3 的實作（`components/editor/use-canvas-pan.ts`）：
  - 在捲動容器的 **capture 階段**攔下 `pointerdown`（手形工具的左鍵、按住空白鍵的左鍵、任何時候的中鍵），`preventDefault` + `stopPropagation`：事件不會到達 Konva，物件不會被選取或拖曳，瀏覽器也不送出後續的相容 `mousedown`。
  - 平移只改容器的 `scrollLeft/Top`，由既有的 `onScroll` 更新畫布位移，縮放錨點等邏輯不受影響；不 dispatch。
  - 空白鍵只在焦點不在任何控制項（`document.body`）時當成暫時手形：輸入框照常打空白，工具列按鈕照常用空白鍵觸發。視窗失去焦點時放開。
  - 中鍵另外攔 `mousedown`，避免 Windows 的自動捲動模式。
  - 可平移的範圍 = 捲軸的範圍（頁面與所有物件的外框 + 200px 邊距），不是 tldraw 的無限畫布。

### 4.3 UI 元件（`components/editor/bottom-toolbar/`）

- `bottom-toolbar.tsx`：主工具列，浮在畫布容器下方中央（`absolute`，不佔版面，不影響畫布尺寸計算）。
- `action-bar.tsx`：動作列，貼在主工具列左上方。
- `shape-picker.tsx`：`^` 展開的圖形選單（shadcn `Popover` 或 `DropdownMenu`）；選了圖形之後，主工具列的圖形按鈕顯示「最近用過的圖形」。
- 按鈕都有 Tooltip，顯示名稱與快捷鍵。

- 步驟 2 的實作細節：
  - 元件放在 `components/editor/bottom-toolbar.tsx` 一個檔案（主工具列 + 動作列 + 圖形選單，約 230 行），沒有拆成資料夾。
  - 圖形清單（種類 / 名稱 / icon）抽到 `components/editor/shape-options.ts`，「元素」面板與工具列共用。
  - `useChooseTool`（`lib/editor/use-choose-tool.ts`）是工具列按鈕與快捷鍵共用的入口；**步驟 2 的文字 / 圖形工具先把物件加到頁面中央再回到選取**，步驟 4 改成到畫布上點擊 / 拖曳建立。文字工具用「副標題」樣式。
  - 快捷鍵加在 `use-editor-shortcuts.ts`：工具鍵（按住不放只觸發一次、選字中不觸發）、Ctrl+D（以 `event.code` 比對，並攔下 WebView2 的「加入我的最愛」）、沒有選取時 Esc 回到選取工具。`menu-structure.test.ts` 的編輯器快捷鍵清單加上 Ctrl+D。
  - shadcn `DropdownMenuContent` 的寬度預設等於觸發按鈕，圖形格線會被截掉；改用 inline `width: max-content`（專案的 `cn` 不會合併衝突的 Tailwind class，用 class 覆寫不保險）。

### 4.4 與現有面板的關係

「文字」「元素」面板保留：面板有預設樣式（標題 / 副標 / 內文）與說明，工具列負責快速建立。兩者都呼叫 `element-factory`，不重複寫建立邏輯。

## 6. 決定

使用者已確認（2026-09-30）：

| 項目 | 決定 |
|---|---|
| 互動方式 | **工具模式**：先選工具，再到畫布點擊或拖曳建立 |
| 第一版工具範圍 | **只做現有物件類型**：選取、手形、文字、圖形、圖片；畫筆 / 箭頭 / 便利貼等之後再說 |
| 復原 / 重做 | **移到底部動作列**，上方系統控制列拿掉 |
| 建立物件之後 | **回到選取工具** |
