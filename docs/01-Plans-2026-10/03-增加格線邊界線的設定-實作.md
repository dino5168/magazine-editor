# 格線、邊界參考線與對齊線的樣式設定：實作計畫

任務檔：`03-增加格線邊界線的設定.md`（同目錄；任務檔寫輸出到 `01-…-實作.md`，照任務檔編號命名為 `03-`）。參考圖：`Images/現行格線與參考線設定.png`。

## 現況

- 「格線與參考線」對話框（`components/app/settings/grid-dialog.tsx`，Ctrl+,）：顯示格線、間距、吸附格線、顯示邊界參考線；按「確定」寫入 App 偏好（`Preferences`，localStorage）。對話框的遮罩會**模糊整個畫面**（shadcn `DialogOverlay` 的 `backdrop-blur-xs`）。
- 畫線在 `components/editor/page-guides.tsx`，樣式寫死成常數：
  | | 顏色 | 透明度 | 線寬 | 虛線（螢幕 px） |
  |---|---|---|---|---|
  | 格線 `PageGrid` | `#94a3b8`（slate-400） | 0.45 | 1 px | 2 + 3 |
  | 內容區對齊線 1/4、3/4 | `#6366f1`（indigo-500） | 0.55 | 1 px | 4 + 3 |
  | 內容區對齊線 1/2 | `#6366f1` | 0.85 | 1.5 px | 6 + 3 |
  | 邊界參考線 `MarginGuide` | `#ec4899`（pink-500） | 1 | 1 px | 4 + 3 |
- 線寬與虛線都除以 zoom：不管縮放多少，在螢幕上都一樣粗。
- 內容區對齊線**沒有自己的開關**，跟著「顯示格線」。

## 已確認（2026-10-08，使用者）

1. 格線、邊界參考線、**內容區對齊線**三種線各自可以設定**顏色、線型、粗細**。
2. 粗細用**螢幕 px**（縮放時粗細不變，和現在一樣）。
3. 內容區對齊線**一組樣式**，1/2 自動比 1/4（3/4）明顯（粗 1.5 倍、較不透明），維持現在的效果。
4. 內容區對齊線有**自己的開關**：對話框、「視圖」選單、TopBar 都有（和格線、邊界參考線一樣，`VIEW_TOGGLES` 加一筆）。
5. 對話框**即時預覽**：改樣式時畫布馬上跟著變，「取消」/ Esc 還原。
6. **「設為預設」= 存成我的預設；「恢復預設」= 回到我的預設**（沒設過時回到原廠值）；另有「原廠設定」回到軟體原本的樣式。

## 設計

### 資料（App 偏好，存這台電腦，不存進專案、不進復原歷史、不匯出）

```ts
interface GuideLineStyle {
  color: string;               // #rrggbb 或 #rrggbbaa（只能從調色板選，含不透明度）
  dash: Stroke["dash"];        // "solid" | "dashed" | "dotted"，比例沿用 stroke.ts 的 dashPattern
  width: number;               // 螢幕 px，0.5–4，步進 0.5
}
interface GuideLineStyles { grid; contentGuides; margins: GuideLineStyle }

Preferences += {
  showContentGuides: boolean;                 // 新開關
  lineStyles: GuideLineStyles;                // 目前的樣式
  lineStyleDefaults: GuideLineStyles | null;  // 「設為預設」存的；null = 沒設過，用原廠值
}
```

- **原廠值 = 現在的外觀**：格線 `#94a3b873`（slate-400、45%）虛線 1 px；對齊線 `#6366f1d9`（indigo-500、85%，即 1/2 線的樣子）虛線 1 px；邊界 `#ec4899` 虛線 1 px。唯一差別：虛線比例改用 `dashPattern`（1 px 時 3 + 3），和現在的 2 + 3 / 4 + 3 差一點。
- 1/2 對齊線：粗細 × 1.5；1/4、3/4：不透明度 × 0.65（85% × 0.65 ≈ 55%，和現在一樣）。
- **舊偏好紀錄的升級**：沒有 `showContentGuides` 時讀成 `grid.visible`（現在對齊線跟著格線，升級後看到的一樣）；之後兩者獨立。沒有 `lineStyles` 時讀成原廠值。
- 「預設值」只包含**三種線的樣式**（顏色 / 線型 / 粗細），不含顯示開關、間距與吸附。

### 即時預覽

- `PreferencesProvider` 加一個**不存檔的預覽值**：`usePreviewPreferences()` 設定後，`usePreferences()` 回傳預覽值（畫布、TopBar 都跟著變），但**不寫入 localStorage**；設回 `null` 就回到原本的值。
  - 不用「邊改邊存、取消時寫回」：那樣對話框開著時關閉視窗，沒按確定的修改也會被存下來。
- 對話框：草稿每次變更 → 設預覽；「確定」→ 寫入偏好並清除預覽；「取消」/ Esc / 關閉 → 清除預覽。
- 預覽要看得到畫布：這個對話框**不模糊背景**、**靠右放**（不蓋住頁面中間）。shadcn 的 `DialogContent` 一定會畫模糊遮罩（`components/ui/` 不改），所以 `SettingsDialog` 加一個選項，改用 `components/ui/dialog.tsx` 已匯出的 `DialogPortal` / `DialogOverlay` / Radix `Content` 自己組（遮罩透明、不模糊，點遮罩仍會關閉）。

- 「恢復預設」「原廠設定」只改**草稿**（預覽跟著變，按「確定」才生效）。
- 「設為預設」**立即**把草稿的三種樣式存成我的預設（toast「已設為預設」），不關閉對話框，也不影響「取消」。
- 顏色用 `ColorPicker`（含不透明度 slider），Popover 疊在對話框上。

## 不重複造輪子（重用清單）

| 需要 | 重用 |
|---|---|
| 顏色（含不透明度） | `ColorPicker` / `withAlpha` / `colorAlpha`、`isElementColor` 驗證 |
| 線型與預覽 | `Stroke["dash"]`、`dashPattern`、`style-controls.tsx` 的 `DASH_OPTIONS` / `DashPreview` |
| 顏色 / 粗細 / 線型的控制項 | 從物件邊框的 `StrokeFields` 抽出 `LineStyleFields`，屬性面板與對話框共用 |

| 偏好讀寫與驗證 | `Preferences` / `parsePreferences`（逐欄驗證、壞掉的欄位回預設） |
| 第四個開關 | `VIEW_TOGGLES` 加一筆 → 選單指令、勾選狀態、TopBar 按鈕自動有 |
| 對話框外框 | `SettingsDialog` / `SettingsDialogFooter`（`note` 位置放左側按鈕） |

不新增套件、不改檔案格式、不改 Rust、不改 `components/ui/`。

## 檢核（可能的問題）

1. **ColorPicker 在 Dialog 裡**：Popover 疊在 Dialog 上；Esc 應該先關 Popover（Radix 巢狀層），步驟 5 實測。
2. **預覽不能存檔**：預覽值只在 React state，`savePreferences` 只看正式的值；對話框開著時關閉視窗不會留下沒確定的修改。
3. **預覽與 TopBar**：對話框是 modal，TopBar 按不到，不會出現「預覽中又從 TopBar 改」的衝突；快捷鍵在 dialog 內不觸發。
4. **點線在 1 px 時**：`dashPattern("dotted", 1)` = 0 + 2、圓頭，點直徑 1 px；步驟 2 截圖確認看得到。
5. **效能**：每種線仍是一個 Shape 畫所有線；樣式只換屬性，不增加節點。預覽時每次改值畫布重畫一次，和現在按「確定」時一樣。
6. **偏好欄位變多**：`parsePreferences` 逐欄回預設，舊紀錄、壞紀錄都不會讓整份偏好失效。
7. **升級時對齊線的開關**：缺欄位時讀成 `grid.visible`，所以預設（格線關）的人升級後也看不到對齊線，和現在一樣；之後可以單獨打開。
8. **對話框變高**：三區 + 頁尾，在 768 px 高的視窗要能捲動（`max-h` + 捲動），步驟 5 確認。
