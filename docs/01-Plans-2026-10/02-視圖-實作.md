# 視圖：格線與參考線的開關：實作計畫

任務檔：`02-視圖.md`（同目錄；任務檔寫輸出到 `01-視圖-實作.md`，因為 `01-` 已經是「修改新增專案流程」，這份照任務檔編號命名為 `02-`）。參考圖：`Images/現行格線與參考線設定.png`、`Images/現行的TopBar.png`。

## 現況

- 格線、吸附、邊界參考線都是 App 偏好（`Preferences.grid.visible` / `grid.spacing` / `grid.snap`、`showMargins`，存 localStorage），只能從「設定 → 偏好設定 → 格線與參考線...」（Ctrl+,，`grid-dialog.tsx`）修改，要按「確定」。
- 「視圖」選單只有一個勾選項目「尺規」（`view.rulers`）。勾選狀態由 `home-page.tsx` 的 `isChecked` 讀偏好，handler 直接切換偏好。目前是寫死的 `command === "view.rulers"` 判斷。
- TopBar（`editor-top-bar.tsx`）：左邊文件名稱；右邊縮小 / 縮放比例 / 放大 ｜ 匯出 PDF。中間大片空白。

## 設計建議

### 任務 1：視圖選單

「視圖」照 Affinity / Illustrator 的慣例，放「畫面上看得到、存這台電腦、不影響輸出」的開關：

```
視圖(V)
  ✓ 尺規
  ─────────
  ✓ 格線
  ✓ 邊界參考線
    吸附格線        ← 建議一起加（見 Q2）
```

- 都是勾選項目，按下立即切換（和「尺規」一樣），不用「確定」，不進復原歷史。
- 與「格線與參考線」對話框改的是**同一份偏好**，兩邊永遠一致；對話框保留（間距只在那裡和 TopBar 調）。
- 勾選狀態與切換改成**一張表**（`VIEW_TOGGLES`：指令 id → 讀偏好 / 切換偏好），選單、TopBar 共用，取代 `home-page.tsx` 寫死的判斷。

### 任務 2：放在 TopBar 還是另一條 ToolBar

**建議：直接放在 TopBar 中間偏右（縮放的左邊），不加新的一列。**

```
[≡] 文件名稱 ..................  [▦][⊞][🧲] 5 mm ▾ │ ⊖ 131% ⊕ │ [匯出 PDF]
                                  格線 邊界 吸附 間距
```

理由：
1. TopBar 中間本來就是空白，放得下一組按鈕；多一列會讓畫布少 40 px 高，而且只有 3–4 個按鈕的一整列很空。
2. 這些是「畫面顯示」的控制，和旁邊的縮放同一類，放在一起好找（Affinity Publisher 的吸附、Figma 的檢視選項都在頂端工具列）。
3. 不改版面 grid，畫布尺寸計算不受影響。

做法（重用既有元件）：
- 三個切換鈕用 `IconButton` + `aria-pressed`（同 `PageViewToggle`、底部工具列的做法），按下時按鈕有底色。
- 間距：小下拉（Popover）裡放 `MmField`（含 − / ＋，1–100 mm，同對話框）與「更多設定...」（開「格線與參考線」對話框）。不直接放輸入框，因為中欄最窄 480 px（`CANVAS_MIN_WIDTH`），放不下。
- 中欄窄時文件名稱先縮（`min-w-0` + 現有的 `truncate`），按鈕不換行。

另一個選擇（不建議）：TopBar 上方另加一條 ToolBar。好處是以後可以放更多工具（對齊、分佈…）；壞處是畫布變矮、目前內容太少。之後真的需要放對齊工具時再加也不遲。

## 檢核（可能的問題）

1. **選單測試**：每個指令只能出現一次、快捷鍵不能重複或和編輯器衝突 → 新增快捷鍵（若有）要過這個測試。
2. **快捷鍵與輸入法**：用 `event.code` 比對（`Quote` / `Semicolon`），注音輸入法下 `key` 會是 `Process`，沿用既有機制沒問題。WebView2 沒有預設佔用 Ctrl+' / Ctrl+;。
3. **對話框開著時**：選單快捷鍵在 dialog 內不觸發；對話框的草稿是開啟當下的值，開著時不可能從選單改到偏好，不會有不同步。
4. **吸附格線在格線隱藏時也有效**（既有規則）：TopBar 的吸附鈕要獨立於格線鈕，不能因為格線關掉就停用，避免使用者以為吸附也關了。
5. **TopBar 寬度**：中欄最窄 480 px；名稱（最寬 256 px）+ 檢視組（約 150 px）+ 縮放（約 120 px）+ 匯出（約 100 px）> 480 → 名稱必須能縮；步驟 3 驗證。
6. `home-page.tsx` 的 `MasterEditBanner` 只看 `showRulers`，不受影響。
