Claude Code（MCP client） 橋接程式 magazine-mcp.exe App 的 Rust 端 App 的前端（WebView）

1. 元件與連線

Claude Code 透過 stdio 啟動橋接程式；橋接程式不碰文件，只把工具呼叫經 named pipe 轉給使用者已經開著的 App。文件狀態在前端的 reducer，所以工具最後由前端執行。

3. 例外情況

App 沒開

橋接程式連不到 pipe，回傳工具錯誤「請先開啟雜誌編輯軟體」。工具清單仍看得到（內嵌在橋接程式）。

App 沒開放 MCP（步驟 6 起）

偏好設定的開關關著時 Rust 不開 pipe，同上回傳中文錯誤並提示去哪裡開啟。

參數不合法

zod 或既有驗證失敗 → 回傳「fontSize 必須是 1–999 之間的數字」這類訊息，文件不變，AI 可以自己修正後重試。

前端沒回應

Rust 端 30 秒逾時，回傳錯誤；之後才到的回應丟掉。

會開對話框的指令

run_command("file.saveAs") 觸發後立即回傳「已在 App 開啟對話框」，存檔位置由使用者在 App 裡選（不讓外部指定路徑）。

不滿意 AI 的修改

一次工具呼叫最多一筆復原紀錄：在 App 按 Ctrl+Z，或請 Claude 呼叫 undo。

6. 一步一步

  1. 自動化指令層：工具定義（zod）、四個查詢、產生 mcp-tools.json。純邏輯 + vitest。
  2. App 端通道：Rust named pipe ↔ Tauri event ↔ 前端，用 PowerShell 直接連 pipe 驗證。
  3. 橋接程式 + Claude Code：magazine-mcp.exe、.mcp.json，端到端驗證唯讀工具（第一階段的通訊驗證完成點）。
  4. 指令工具：list_commands / run_command。
  5. 編輯工具：reducer 加可選 pageId、patch 驗證、九個編輯工具。
  6. 開關、狀態、文件：偏好設定開關（預設關）、TopBar 狀態圖示、CLAUDE.md 與 progress.md。
