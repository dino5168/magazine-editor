# 06 畫面調整：工具面板停靠區改成 Tabs（實作計畫）

任務檔：`06-畫面調整-工具面板停靠區.md`（不 commit）。截圖：`Images/工具面板右側顯示.png`（右側五個面板上下堆疊，全部收合才放得下）。

## 任務

1. 停靠區目前是**垂直堆疊**：每個面板一條標題列，開越多每個越矮。改成 **Tabs**。
2. 左、右兩側都改。
3. 操作參考 **Affinity** 的 Studio 面板。

## Affinity 的做法（參考對象）

- 一側由上到下是幾個**面板群組**；每個群組頂端是一排**頁籤**，一次顯示一個面板。
- 點頁籤切換；拖曳頁籤可以在同一排換位置、拖到別的群組的頁籤列**併入**、拖到群組之間**另成一組**、拖到另一側。
- 群組可以收合（只剩頁籤列）；展開的群組分配高度。
- 從「視窗」選單打開面板會出現在群組裡。

## 新的模型（草案）

```ts
interface DockGroup {
  readonly panels: readonly PanelId[]; // 頁籤順序，至少一個
  readonly active: PanelId;            // 目前顯示的頁籤
  readonly collapsed: boolean;         // 只剩頁籤列
}
interface DockLayout {
  readonly left: readonly DockGroup[];  // 由上到下
  readonly right: readonly DockGroup[];
  readonly width: { left: number; right: number };
}
```

規則：一個面板在整個版面最多出現一次；群組不會是空的（最後一個頁籤關掉 = 群組消失）；`active` 一定在 `panels` 裡。

純函式（都是「沒變化回傳同一個參考」）：

- `togglePanel(layout, id)`：打開 = 加到預設那一側**第一個群組**的最後並設為目前頁籤（那側沒有群組就新建一組）；已打開 = 關閉。
- `closePanel`、`activatePanel(layout, id)`、`toggleGroupCollapsed(layout, side, groupIndex)`。
- `dropPanel(layout, id, target)`，`target` 兩種：
  - `{ side, kind: "tab", group, slot }`：插入某群組頁籤列的第 slot 個位置（併入 / 同列換位置），並設為目前頁籤；
  - `{ side, kind: "group", slot }`：在群組之間另成一組。
- `parseDockLayout`：逐欄驗證（未知 / 重複 id 丟掉、空群組丟掉、`active` 無效改成第一個）。

## 檢核

- **「頁面」面板**：`scroll: "self"` 需要「內容填滿、自己分高度」，群組的內容區照舊給 `flex-1 min-h-0` 就好；它的兩區收合 / 高度比例存在自己的 localStorage，和停靠模型無關。
- **切換頁籤的成本**：屬性 / 圖層 / 頁面面板都訂閱編輯器狀態；看不到的面板如果還掛著，每次編輯都會 re-render（頁面縮圖還是 Konva Stage）。所以背景頁籤卸載（決定 3）。
- **選單勾選**：`isPanelVisible` 的意思從「看得到」變成「在某個群組裡（可能是背景頁籤）」。勾選 = 已打開，取消勾選 = 關閉，和 Affinity 一致；要「打開背景頁籤」就點頁籤。
- **拖曳中不重畫畫布**：維持現在的原則——只有目標改變才 setState，ghost 直接改 style。
- **`data-dock-panel` 命中判斷**：現在用 `:scope > [data-dock-panel]` 算插入位置；改成群組後換成 `data-dock-group`，頁籤用 `data-dock-tab`。
- **其他使用 `startPointerDrag` 的地方**（頁籤列、頁面面板分區、素材管理）不受影響：這次只改 `use-dock-drag.ts` 的命中判斷。
- **檔案格式 / Rust**：不涉及；版面是 App 偏好（localStorage）。

## 決定（2026-10-09 與使用者確認）

1. **多組上下堆疊**（Affinity）：一側可以有好幾個群組，每組頂端一排頁籤；屬性與圖層可以同時看到。（考慮過「一側只有一組頁籤」：最簡單，但同時只看得到一個面板。）
2. **舊版面改用新預設**：v2 的版面不轉換，只保留兩側寬度；要的面板從「工具面板」選單再打開。（考慮過「每個面板各成一組」「每側併成一組」。）
3. **背景頁籤卸載**：看不到的面板不掛載，編輯時不多做 re-render。代價：面板自己的暫時狀態（屬性面板的子分頁、捲動位置、「限制寬高比」）切走再切回來會重置。
4. **頁籤放不下時水平捲動**：滾輪橫捲、目前頁籤自動捲進畫面，和頁面頁籤列相同的操作。（考慮過換行成多排、窄時只顯示 icon。）

## 設計建議（待使用者確認，步驟 1 開始前可以改）

- **新的預設版面**，讓頁籤一開始就看得到：
  - 左：上 `[範本 | 文字 | 相片 | 元素 | 素材 | 背景]`，下 `[頁面]`
  - 右：上 `[屬性]`，下 `[圖層]`
  - 「繪圖」目前是佔位，不放進預設。
- 頁籤上的關閉鈕只在滑過 / 目前頁籤時顯示（Affinity 沒有關閉鈕，靠選單；保留關閉鈕是因為現在的面板有）。
- 之後可以另排：群組之間的分隔條調整高度（現在是平分）、雙擊頁籤列收合（Affinity 的做法，先用收合箭頭）。
