# 17 文件色票（Swatches）實作計畫

規劃與討論：`docs/Plans-Color-System/01-色票系統規劃.md`（使用者的需求）→ `docs/Plans-Color-System/Color-System.html`（評估、架構、Q1–Q8 的決定）。本計畫要 commit。

## 1. 需求理解

- 顏色目前只能從 Tailwind 色票選（2026-09-30 決定）。雜誌需要**品牌色、指定色**：文件裡要有一組**具名的顏色（色票）**，可以自訂 hex。
- 文字、圖形、邊框、陰影、頁面背景、頁碼、文字樣式都可以**連到色票**；**改色票 = 所有連到它的地方一起變**（一筆復原）。
- 管理入口在「設定 → 文件 ▸ 色票...」；平常套用在調色板裡。
- 使用者提出的 PANTONE / ICC → Token 引擎 → Color Tokens → Style 四層，這一輪只做「Color Tokens（文件色票）」並讓 Style 引用它（評估見 `Color-System.html` 第 3 節）。

## 2. 決定（使用者 2026-10-12 確認）

| 問題 | 決定 |
|---|---|
| Q1 範圍 | 只做文件色票（sRGB）；PANTONE / ICC / CMYK 不做，資料模型的位置留著（另開「印刷輸出」任務） |
| Q2 Tailwind 色票 | 保留在調色板，當「原色庫」直接選（選了 = 不連色票） |
| Q3 透明度 | **色票不透明**（`#rrggbb`），透明度存在使用處；改色票時保留每個使用處自己的透明度。取代 `03-系統設計優先順序建議.md` 的「含不透明度」 |
| Q4 自訂 hex | 只在「色票...」對話框輸入（自訂色一定有名字）；調色板沒有 hex 輸入框 |
| Q5 覆寫 | 文字樣式的顏色連到色票、文字同色但沒連（或連到別的色票）= **覆寫** |
| Q6 刪除使用中的色票 | **先問**：確認框列出「N 處使用」，選「換成某個色票」或「不替換（保留顏色、取消連結）」 |
| Q7 預設色票 | 新文件帶「文字」`#171717`、「黑」`#000000`、「白」`#ffffff`；新文件的內建三個文字樣式連到「文字」；頁面背景不連；**舊檔讀成沒有色票** |
| Q8 即時預覽 | 第一版不做；對話框按「確定」才套用（同頁碼管理） |

**取代的舊決定**：2026-09-30「顏色只能從 Tailwind v4 色票選、不保留自訂顏色」（`CLAUDE.md`「調色板」、`progress.md` 決定表），在步驟 8 改寫。

## 4. 資料模型（v12）

```ts
// types.ts
/** A named, opaque document color（文件色票）. Uses keep their own copy of the color. */
interface Swatch {
  readonly id: string;
  readonly name: string;   // 去頭尾空白、文件內不重複、長度同文字樣式名稱
  readonly color: string;  // #rrggbb，小寫
}

interface EditorDocument { …; readonly swatches: readonly Swatch[] }  // 陣列順序 = 顯示順序

// 連結欄位：null = 沒連色票
interface TextStyle    { …; fill; readonly fillSwatchId: string | null }       // 文字、圖形內文字、文字樣式、頁碼
interface TextShadow   { color; readonly swatchId: string | null; … }
interface Stroke       { color; readonly swatchId: string | null; … }          // 圖形邊框、頁碼框線
interface ShapeElement { …; fill; readonly fillSwatchId: string | null }
interface Sheet        { …; background; readonly backgroundSwatchId: string | null }
```

- **照存實際值**：連到色票的欄位仍存完整的 hex（含使用處的透明度），連結只記 id。畫布與匯出不讀色票表，舊檔不用改寫。
- **規則**：連到色票時，實際值的 RGB = 色票的顏色，透明度是使用處自己的（`withAlpha(swatch.color, alpha)`）。驗證（TS 與 Rust）只檢查**引用的色票存在**，不檢查 RGB 相等（同 `require_style` 只查存在）；保持一致是 reducer 的責任。
- 欄位都是必填的 `string | null`（同 `styleId`）：漏設會編譯失敗。Rust 缺欄位時 serde 預設 `None`，**不需要升級步驟**；舊檔 `swatches` 讀成空陣列。
- **內建色票的 id 固定**：`swatch-text` / `swatch-black` / `swatch-white`（`BUILT_IN_SWATCH_IDS`），新文件的內建文字樣式以它連結。
- `tests/fixtures/default-text-styles.json`（Rust 升級 v8 以前的舊檔也用）**維持 `fillSwatchId: null`**：舊檔沒有色票，連結了會驗證失敗。新文件的連結在 `createBlankDocument` 才加。
- 預留：`Swatch` 之後可以加 `cmyk?` / `spot?`（不在這一輪）。

## 5. 操作方式

### 5.1 調色板（`ColorPalette`）

```
┌ 文字顏色                     品牌紅 · 80% ┐   ← 連到色票時顯示色票名稱
│ 文件色票                                    │
│ ■ ■ ■ ■ ■ ■                [管理色票...]   │   ← 新增的一區（呼叫端傳入 swatches 才顯示）
│ ─────────────────────────────────────────── │
│ 色系 ■■■■■■■■■■■■ / ■■■■■■■■■■■■         │   ← 原本的 Tailwind
│ 深淺 ■■■■■■■■■■■                           │
│ 不透明度 ────●──── 80%                      │
└─────────────────────────────────────────────┘
```

- 點色票 = `{ color: withAlpha(色票, 目前透明度), swatchId }`；點 Tailwind 色 = `swatchId: null`；拖不透明度 = 保留 `swatchId`。
- 色票格子滑過顯示名稱（`title` / `aria-label`），目前連到的那一格有選取框。
- 「管理色票...」關掉 Popover、開「色票...」對話框。
- 文件沒有色票時這一區只顯示「管理色票...」（舊檔第一次就找得到入口）。

### 5.2 「設定 → 文件 ▸ 色票...」對話框

```
色票                                              ✕
┌──────────────────────────────────────────────────┐
│ ■ 文字      #171717    使用 12                  ⋮│
│ ■ 黑        #000000    使用 0                   ⋮│  ← 雙擊名稱改名；拖曳左邊把手排序
│ ■ 白        #ffffff    使用 3                   ⋮│
│ ■ 品牌紅    #d6202f    使用 7                   ⋮│
└──────────────────────────────────────────────────┘
[＋ 新增色票]
── 選中的色票 ─────────────────────────────────────
名稱 [品牌紅      ]   顏色 [#d6202f] ■   [從 Tailwind 選 ▾]
                                         取消   確定
```

- 草稿：所有修改（新增、改名、改色、刪除、排序）都在對話框裡，「確定」一次 dispatch（一筆復原），「取消」/ Esc 放棄。
- 顏色欄位：hex 輸入（`#` 可省略、大小寫都收、3 位數展開？見第 8 節）+ 旁邊的 `ColorPicker`（只有 Tailwind 區、沒有不透明度）。
- 刪除：沒人用 → 直接從草稿移除；有人用 → 確認框「『品牌紅』用在 7 處。刪除後：( ) 換成 [色票 ▾]　( ) 不替換（保留顏色、取消連結）」。
- 使用數 = 目前文件裡連到它的地方（草稿裡改色不影響使用數）。
