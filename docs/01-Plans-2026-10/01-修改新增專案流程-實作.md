# 修改新增專案流程：實作計畫

任務檔：`01-修改新增專案流程.md`（同目錄）。參考圖：`Images/修改新增專案流程.png`（左：紙張卡片）、`Images/現行系統頁面設定.png`（右：直橫、邊界）。

## 現況

- 「檔案 → 新增」（Ctrl+N）：`use-project-commands.ts` 的 `newImpl` = `resolveUnsaved()`（儲存 / 不儲存 / 取消）→ `project-context.tsx` 的 `createNew()`：Rust `project_new` 建立未命名專案資料夾 → `createBlankDocument()`（A4 直式、邊界 15 mm、一頁）→ `document/load`。
- 紙張與邊界只能事後在「設定 → 文件 → 頁面設定...」（`page-setup-dialog.tsx`）修改。
- 桌面版啟動時，沒有上次的專案也會呼叫 `createNew()`（同樣直接 A4）。

## 目標流程

```
檔案 → 新增（Ctrl+N）
  → 有未存檔變更？→「儲存 / 不儲存 / 取消」（不變；取消 = 結束）
  → 「新增文件」對話框
       左：紙張卡片（依 ISO A / JIS B / 台灣書刊 / 美規 / 電子書分組，預設選 A4）
       右：直式 / 橫式（預設直式）、寬高、邊界（預設 15 mm）
       [取消] → 什麼都不做，留在目前的文件
       [建立] → project_new → createBlankDocument(所選設定) → 進入編輯
```

順序上先處理未存檔再選紙張：沿用現有的 `resolveUnsaved` → 建立，只在中間插一步；選了「儲存」之後在紙張對話框按取消也沒有損失（只是存了檔）。

## 步驟（每步完成後停下，等使用者說「繼續」）

### 步驟 1：純邏輯（畫面不變）✔ 2026-10-08

- `element-factory.ts`：`createBlankDocument(setup = DEFAULT_NEW_PAGE_SETUP)`，不帶參數時仍是 A4 直式 + `DEFAULT_MARGINS`（啟動與測試的現有呼叫不用改）。
- `DEFAULT_NEW_PAGE_SETUP`（A4 直式 + `DEFAULT_MARGINS`）放在 `element-factory.ts`、`DEFAULT_MARGINS` 旁邊（原本計畫放 `page-setup.ts`，但那樣兩個檔案會互相 import 執行期的值，形成循環）。
- `page-setup.ts`：型別 `PageSetup = { size, margins }`；`page-setup-dialog.tsx` 的 `PageSetupDraft` 改用它。
- 測試（`element-factory.test.ts`）：預設值 = A4 直式 + 15 mm；帶入 B5 橫式與自訂邊界時照用。結果：tsc 通過，vitest 371 個全過。

### 步驟 2：抽出共用的「直橫 / 寬高 / 邊界」欄位（行為不變）✔ 2026-10-08

- 從 `PageSetupForm` 抽出 `PageSetupFields`（`components/app/settings/page-setup-fields.tsx`）：直式 / 橫式按鈕、寬高、邊界、錯誤訊息；受控元件（`value: PageSetup`、`onChange`）。呼叫端給 `sizeHeading`（區塊標題）、可選的 `paperPicker`（放在直式 / 橫式按鈕左邊同一列）、`sizeNote`（寬高下方的提示）與 `errors`（何時驗證由呼叫端決定：頁面設定只在有改動時才驗證）。
- 紙張下拉選單與「頁面尺寸不一致」提示留在「頁面設定」對話框，以 `paperPicker` / `sizeNote` 傳入（新增文件改用卡片，不用下拉）。
- 驗證：無頭 Edge 12 項全過（開啟、初始值與標題、切橫式、左邊界過大時顯示錯誤並停用「確定」、改寬變「自訂」、確定套用、取消放棄、一次 Ctrl+Z 還原、沒有 console 錯誤）；截圖與 `Images/現行系統頁面設定.png` 相同。tsc 通過。

## 檢核（可能的問題）

1. **對話框裡的快捷鍵**：`use-menu-shortcuts` 在焦點位於 dialog 時不觸發，編輯器快捷鍵也一樣，不會在選紙張時誤觸 Ctrl+N / Delete。✔
2. **busyRef**：`exclusive()` 在 `run()` 期間設 busy，對話框是 `run()` 裡 await 的 Promise，期間其他檔案指令（含關閉視窗的 `confirmClose`）會被擋下回傳 false。關閉視窗時對話框開著 → 視窗不關，和現在「另存對話框開著時關閉視窗」相同。✔（記錄在已知行為）
3. **Esc / 點外面**：Radix `onOpenChange(false)` 一律當成取消（resolve `null`），不能讓 Promise 懸著，否則 busyRef 永遠為 true。要寫測試腳本確認。
4. **卡片外框比例**：Tabloid（279 × 432）與電子書 9:16 比例差很多，外框以「固定框內等比縮放」畫，名稱與尺寸對齊在同一高度。
5. **mixed 尺寸提示**只屬於「頁面設定」，不放進共用欄位。
6. **Rust 不用改**：`project_new` 只建立資料夾，文件內容由前端產生；存檔時 `format.rs` 照常驗證尺寸（10–2000 mm）與邊界。
