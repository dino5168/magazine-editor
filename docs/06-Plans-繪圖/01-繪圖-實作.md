## 0. 範圍（使用者決定，2026-10-15）

- 圖形庫放在「**元素**」面板（分類）；「繪圖」面板保留給之後的自由繪圖 / 鋼筆。
- 只做**框型圖形**：A 類（一條封閉路徑）+ B 類（填色外框 + 只描邊的細節線）。
- 參數（梯形斜度、箭頭頭部…）在**屬性面板輸入數字**；畫布上的調整把手另排。
- 圖形定義**自己寫**，外觀參考 draw.io「一般」分類。
- 線條 / 箭頭物件（可拖端點）之後另開任務；連接線不做。
- 不做（之後另排）：有洞的圖形（fill rule）、每個圖形自己的文字區、SVG 轉圖形、把現有多邊形 / 星形改走圖形庫。

## 1. 設計

### 1.1 文件模型（檔案格式 v14）

`ShapeGeometry` 加一個成員（`types.ts` / Rust `format.rs`）：

```ts
/** A shape from the built-in shape library; drawn from `presetPath(preset, params, width, height)`. */
| { readonly kind: "preset"; readonly preset: string; readonly params: Readonly<Record<string, number>> }
```

- `preset`：圖形庫 id（英數與 `-`，≤ 32 字），**發布後不改名**（同紙張 preset 規則）。
- `params`：**具名**參數（和評估文件寫的 `number[]` 不同：具名的參數在檔案、MCP、屬性面板都看得懂，增減參數也不會錯位）。缺少的參數用定義的預設值；超出範圍時畫的時候夾回。
- 檔案驗證（TS `isShapeGeometry` / Rust `validate_geometry`）只檢查**格式**：id 字元與長度、參數名稱字元、最多 8 個、數值有限。**不檢查 id 是否在圖形庫裡**（Rust 不知道圖形庫）。
- 不認識的 preset（例如新版 App 加的圖形，被舊版打開——實際上 v14 會先擋下；或日後刪掉的圖形）：畫布畫成虛線外框 + 「?」，匯出略過並計入 `skippedShapes`（同圖片遺失的處理，不讓匯出失敗）。
- 舊檔不用升級（沒有 preset 圖形）。提升 `SCHEMA_VERSION` 是讓舊版 App 明確說「檔案比較新」。

### 1.2 圖形庫（只在 TypeScript）

`src/lib/editor/shape-presets.ts`：

```ts
interface ShapePresetParam {
  readonly name: string;        // 存進檔案的名稱，例如 "size"
  readonly label: string;       // 屬性面板顯示，例如「斜邊寬度」
  readonly min: number; readonly max: number; readonly step: number;
  readonly default: number;
  readonly unit: "%" | "pt";    // % = 佔寬 / 高 / 短邊的比例（由公式決定），pt = 固定長度，不跟著拉伸
}

interface ShapePreset {
  readonly id: string;
  readonly label: string;               // 「六角形」
  readonly category: ShapeCategoryId;   // 面板分類
  readonly size: Size;                  // 點一下建立時的預設大小
  readonly params: readonly ShapePresetParam[];
  /** 已拉伸到 width × height 的路徑（pt）：fill = 填色 + 描邊；details = 只描邊。 */
  readonly path: (box: Size, params: ResolvedParams) => ShapePath;
}

interface ShapePath {
  readonly fill: readonly PathCommand[];     // 一或多個封閉子路徑
  readonly details: readonly PathCommand[];  // 開放或封閉，只描邊（可以是空的）
}

type PathCommand =
  | { readonly op: "M"; readonly x: number; readonly y: number }
  | { readonly op: "L"; readonly x: number; readonly y: number }
  | { readonly op: "C"; readonly x1: number; readonly y1: number; readonly x2: number; readonly y2: number; readonly x: number; readonly y: number }
  | { readonly op: "Z" };
```

- 公式**直接算 pt**（不靠 Konva 的 scale），所以拉伸時描邊粗細不變；需要固定長度的部分（圓柱頂部、箭頭頭部）由參數決定。
- **只有 M / L / C / Z**：Konva、Typst `curve`、SVG `<path>` 三端對這四種的行為一致；弧線一律先轉成三次貝茲。
- 寫法：一個小的路徑 builder（`moveTo / lineTo / cubicTo / ellipseArc / close`，`ellipseArc` 用和 Rust `KAPPA` 相同的四分之一圓近似）。形狀固定、曲線多的圖形（雲）直接用 **SVG path 字串**（0–1 的比例座標）寫，交給 **`svgpath`**（npm 2.6.0，MIT，無相依）做 `abs()` / `unshort()` / `unarc()` 正規化，再拉伸到外框。不自己寫 SVG parser。
- `presetPath(preset, params, w, h)`：找定義 → 補預設 / 夾參數 → 算路徑；找不到回 `null`。
- `pathData(commands)`：轉 SVG `d` 字串（Konva `Path` 與面板圖示共用）。

### 1.3 畫布

- `ShapeBody` 的 `preset` case：`<Path data={pathData(fill)} fill stroke…/>` + details 一個 `<Path data=… fill={undefined} stroke…/>`（細節線用同一個邊框樣式；沒有邊框時圓柱等 B 類圖形會看不出形狀，所以這時用填色加深的顏色、1 pt 畫，見 §4 Q6）。
- 選取、Transformer、`bakeTransform`、跨頁複本、主頁、縮圖、圖形內文字都經過 `ShapeBody` / `StaticShape`，不另外改。
- 路徑用 `useMemo`（依 geometry 與寬高）。

### 1.4 匯出：前端算路徑，Rust 只畫

- `ExportRequest` 加 `shapePaths: Record<string, ShapePath>`（以匯出後的 element id 為 key，和 `textLayouts` 同一套：主頁複本 `master:…`、跨頁複本 `spill:…` 都有自己的 key），`buildExportRequest` 在展開主頁 / 跨頁之後算。
- Rust：
  - `ExportRequest.shape_paths`（`#[serde(default)]`），`render.rs` 的 `shape_kind` 遇到 `Preset` 時查 `shape_paths`，轉成新的 `RenderKind::Path(RenderPath { width, height, fill: Vec<Vec<PathSegment>>, details: Vec<Vec<PathSegment>>, fill_color, stroke, detail_stroke })`；查不到 → 略過並計數。
  - 匯出端驗證 `shape_paths`：數值有限、指令數上限（例如 2,000），超過就拒絕（IPC 參數不可信任）。
- `PathSegment` 加 `Close`；每個子路徑是一個 `Vec<PathSegment>`。
- PDF（`template.typ`）：填色部分一個 `curve`（多個 component，每個以 `curve.close` 結束），details 另一個 `fill: none` 的 `curve`；開放的 detail 不 close。
- EPUB / 翻頁書（`markup.rs`）：一個 inline SVG，填色 `<path d>` + details `<path d fill="none">`；半透明顏色沿用 `svg_fill` / `svg_stroke`。
- 圖形內文字照舊（外框內縮 4 pt）。

### 1.5 UI

- **元素面板**：依分類（基本 / 方塊與流程 / 箭頭 / 標註與旗幟）分組，每個按鈕的圖示是同一個 `presetPath` 算出的 inline SVG（不用另找 icon）；原本 5 種（矩形、圓角矩形、圓形、三角形、星形）放在「基本」最前面，行為不變。
- 底部工具列：`EditorState.shapeKind` 從 `ShapeKind` 擴充成「`ShapeKind` 或 preset id」（`ShapeChoice`），「最近用過的圖形」可以是 preset；圖形選單列原本 5 個 + 「更多圖形…」（打開元素面板）。
- 拖曳建立（`createShapeInBox`）：preset 填滿拖曳框；點一下用定義的 `size`。
- 屬性面板「樣式」分頁：preset 的參數欄位（`NumberField`，名稱 / 範圍 / 單位來自定義，一次 = 一筆復原）；「換成…」下拉：換 geometry、保留位置大小填色邊框文字（可以在 preset 與原本 5 種之間換）。
- 圖層面板：preset 的 icon 用同一個 SVG 縮圖（`GEOMETRY_ICONS` 只給 kind，preset 另外處理）；`describeShape` 回傳定義的 `label`。

### 1.6 MCP

- `add_shape` 的 `shape` 參數接受原本 5 種或 preset id，可帶 `params`；`update_element` 可改 `params`（只對 preset）。
- 新工具 `list_shapes`：回傳所有圖形（id、名稱、分類、參數與範圍）。

## 5. 結果紀錄

### 步驟 0：完成（2026-10-15）

- `render.rs`：`PathSegment::Close`（同 SVG：`Move` 開始子路徑、`Close` 封閉，沒有 `Close` 的子路徑不封閉）；`rounded_rect_path` 結尾加 `Close`；`ellipse_path` 從 `pdf.rs` 搬來（回傳 `PathSegment`）；新的 `RenderKind::Path(RenderPath { width, height, outline, fill, stroke, details, detail_stroke })`。步驟 4 之前沒有程式建立它，所以非測試建置加 `#[cfg_attr(not(test), allow(dead_code))]`（步驟 4 移除）。
- `pdf.rs`：`path_segments` 把路徑轉成模板的 `["m"|"l"|"c"|"z", …]`；`RenderKind::Path` 輸出 `kind: "path"` + `details` / `detailStroke`。
- `template.typ`：`"z"` → `curve.close(mode: "straight")`（原本固定加在最後）；`details` 畫成第二個、沒有 fill 的 `curve`。
- `markup.rs`：`svg_path_data` 照資料輸出 `Z`（原本固定加在最後）；`RenderKind::Path` = inline SVG：外框 `<path>` + 細節 `<path fill="none">`；`has_svg` 包含它。
- 測試（cargo 197，+2）：`path_shapes_fill_each_subpath_and_keep_open_details_open`（PDF 點陣：兩個子路徑各自填色、中間不填、細節線不被接回起點、不填色）、`path_shapes_are_inline_svg_with_open_details_left_open`（EPUB 標記），共用 `test_support::path_shape_document`；`outline_paths_start_where_konva_starts_and_close` 改成檢查結尾的 `z`。
- **既有輸出不變**：修改前後各跑 `export_preview` / `epub_preview` / `flipbook_preview` 兩組（fixture 原樣；所有圖形加 3 pt 實線 / 虛線 / 點線邊框，含四角不同的圓角矩形 → `<path>` 與有邊框的橢圓）：PDF 點陣圖、翻頁書所有檔案位元組相同；EPUB 只有每次匯出本來就不同的 `content.opf` 識別碼與修改時間不同，頁面 XHTML 相同。`cargo check` 沒有警告。

### 步驟 1：完成（2026-10-15）

- 模型：`ShapeGeometry` 加 `{ kind: "preset"; preset; params }`（TS `types.ts`、Rust `format.rs` 的 `ShapeGeometry::Preset { preset: String, params: BTreeMap<String, f64> }`，`params` 缺少時讀成空的）；`SCHEMA_VERSION` 14。
