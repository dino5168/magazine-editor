# 自由繪圖（線條、箭頭、鉛筆）實作計畫

> 任務檔：`03-自由繪圖-需求分析。.md`；可行性評估與使用者決定：`03-自由繪圖-需求分析-評估.md`（2026-10-15）。
> 做法：一步一步做，**每一步做完停下來等使用者說「繼續下一步」**；commit 只在使用者要求時做。

---

## 0. 範圍（使用者決定，2026-10-15）

- 新物件類型 **`line`**：直線 → 折線 → 曲線（逐點點擊、自動平滑，不做貝茲控制把手）→ **鉛筆**（這次一起做，筆觸粗細固定）。
- 兩端各自的箭頭：無 / 開放 `>` / 實心三角；大小可調。
- 線型：既有的實線 / 虛線 / 點線 + **點劃線**（圖形邊框也能用）；**雙線**只給直線 / 折線（可選的步驟 12）。
- 入口：底部工具列「線條」工具（`L`）與「鉛筆」工具（`P`）；「繪圖」面板放常用組合（取代佔位卡片）。
- 分叉箭頭：圖形庫加一個框型圖形（「箭頭」分類）。
- 不做（之後另排）：鋸齒 / 波浪花樣、線帽選項、鉛筆壓力 / 粗細變化、貝茲控制把手、連接線、線上的文字。

## 1. 設計

### 1.1 文件模型（檔案格式 v15）

`types.ts`（Rust `format.rs` 對應）：

```ts
export interface LinePoint { readonly x: number; readonly y: number }

export type LineArrowhead = "none" | "open" | "triangle";

export interface LineEnd {
  readonly arrowhead: LineArrowhead;
  /** 箭頭大小的倍數（0.5–5，預設 1；UI 的小 / 中 / 大 = 0.7 / 1 / 1.5），實際尺寸見 §1.2。 */
  readonly scale: number;
}

export interface LineElement extends BaseElement {
  readonly type: "line";
  /** 2–500 個點（MAX_LINE_POINTS），相對於 (x, y)。正規化後 (x, y) = 點的外接框左上角。 */
  readonly points: readonly LinePoint[];
  /** straight = 依序連直線（2 點 = 直線，更多 = 折線）；smooth = 穿過每個點的平滑曲線（曲線、鉛筆）。 */
  readonly path: "straight" | "smooth";
  /** single = 一條；double = 兩條平行線（只給 straight，見步驟 12）。 */
  readonly compound: "single" | "double";
  readonly stroke: Stroke;          // 一定有（不可 null）；色票連結照 Stroke.swatchId
  readonly start: LineEnd;          // 第一個點那一端
  readonly end: LineEnd;            // 最後一個點那一端
}
export type CanvasElement = TextElement | ShapeElement | ImageElement | LineElement;
```

- **一次把欄位定好**（`path`、`compound` 從步驟 1 就在模型裡），v15 在整個任務期間只升一次，不會為了曲線、雙線再升版。
- `Stroke.dash` 加 `"dashDot"`（步驟 0）也算在 v15。
- **(x, y) 是點的外接框左上角**（和其他物件同一個慣例）：圖層、框選、捲動範圍、跨頁、尺規照常運作。改點的時候由純函式 `withLinePoints(line, pagePoints)` 重新正規化。
- `rotation`：保留在模型，UI 不提供旋轉（角度由端點決定）；畫布、匯出照常套用（MCP 可以給）。正規化要考慮旋轉（點先轉到頁面座標再算回來）。
- 驗證（TS `isLineElement` / Rust `validate_element`，同規則）：點數 2–500、座標有限且 |v| ≤ 1e6、`stroke` 照 `validate_stroke`、`scale` 0.5–5、列舉值。`compound: "double"` 搭 `smooth` **不算錯**（畫成單線；UI 不讓選），避免一個檔案因為這個打不開。

### 1.2 路徑：`lib/editor/line-path.ts`（純函式，畫布、圖示、匯出共用）

```ts
interface LinePaths {
  readonly stroke: PathCommand[];      // 線本身（開放路徑；雙線時是兩個子路徑）
  readonly fills: PathCommand[];       // 實心箭頭（封閉，填線的顏色，不描邊）
  readonly outlines: PathCommand[];    // 開放箭頭（只描邊，實線，線的顏色與粗細）
}
linePaths(line: LineElement): LinePaths
```

- 使用 `shape-path.ts` 的 `PathBuilder` / `PathCommand` / `pathData` / `pathBounds`，只輸出 M / L / C / Z。
- **箭頭尺寸**：`w0 = max(stroke.width, 1.5)`（細線的箭頭才看得到）；長度 = `4 × w0 × scale`、寬度 = `3.5 × w0 × scale`（步驟 2 畫預覽給使用者看後定案，常數 `ARROWHEAD_LENGTH` / `ARROWHEAD_WIDTH` / `ARROWHEAD_MIN_LINE_WIDTH`）。UI 的小 / 中 / 大 = 0.7 / 1 / 1.5。
- **尖端在端點上**，方向 = 端點的切線（直線 / 折線：最後一段；平滑曲線：最後一段貝茲的控制點方向，控制點和端點重合時退回前一個點）。
- **實心三角**：線在那一端縮短，終點落在頭部裡面（被頭部完全蓋住，不留接縫、尖端不冒出線頭）；縮短量 > 線長時線不畫（只剩頭）。
- **開放箭頭**：兩撇以端點為尖，描邊的 miter 在尖端略微超出端點（≤ 線寬，圖形邊框同一個規則）；線不縮短。
- **箭頭永遠是實線**：虛線只套在 `stroke` 路徑。
- **平滑曲線**（步驟 9）：Catmull-Rom（均勻，張力 0.5）轉三次貝茲：`c1 = p1 + (p2 − p0) / 6`、`c2 = p2 − (p3 − p1) / 6`，兩端重複端點。曲線穿過每個點。
- **雙線**（步驟 12）：兩條各 `width / 3` 粗、中心距 `2 × width / 3` 的平行線（總寬 = 線寬，Word / InDesign 的「細細」雙線）；折線的轉角用兩條偏移線段的交點（夾角太尖時限制長度，同 miter limit 10）。
- 外接框（`lineBounds`）= 點（平滑曲線用 `pathBounds`）的外接框，**不含**線寬與箭頭（同圖形「邊框不算進外框」）。

`lib/editor/line-geometry.ts`（純函式）：`withLinePoints`（正規化）、`linePagePoints`（含旋轉的頁面座標）、`lineLength` / `lineAngle` / `withLengthAngle`（屬性面板）、`constrainAngle`（Shift：45° 的倍數）、`simplifyPoints`（RDP，鉛筆用）。

### 1.3 畫布

- `LineNode`（`canvas-elements.tsx`）：一個 Group（x, y, rotation）裡 3 個 `Konva.Path`（`stroke`、`fills`、`outlines`），資料來自 `linePaths`（`useMemo`）。`stroke` 那個設 `hitStrokeWidth = max(線寬, 8 / zoom)`、`fillEnabled: false`；其他兩個 `listening={false}`。`StaticElement` 也畫它（主頁內容、對頁複本、縮圖）。
- **Transformer**：`TRANSFORMER_OPTIONS.line` = 沒有控制點、不能旋轉、不畫框（單選時改畫端點把手）；多選時照舊只能移動，線也跟著整組移動。`bakeTransform` 對線只回寫 x / y。
- **端點把手**（`line-handles.tsx`，步驟 4）：單選一條線時，在目前頁的 Group 裡為每個點畫一個圓點（螢幕 8 px），點數 > 30（鉛筆）時只畫頭尾。拖把手走 Konva drag（`dragBoundFunc` 處理 Shift 角度與格線吸附），拖曳中只改本地預覽（不 dispatch），`dragend` 一次 `element/update { x, y, points }`（一筆復原）。
- 跨頁複本、主頁內容、縮圖都經過 `StaticElement`，不另外改。

### 1.4 工具與建立（`use-canvas-line.ts`）

- `ToolId` 加 `line`、`pencil`；`EditorState.lineKind`（`straight` / `arrow` / `doubleArrow` / `polyline` / `curve`，「最近用過」，同 `shapeKind`）。快捷鍵 `L`（線條）、`P`（鉛筆）（`TOOL_SHORTCUTS`，`menu-structure.test.ts` 會查衝突）。
- 和 `use-canvas-create` 一樣在捲動容器的 **capture 階段**攔 `pointerdown`；按下處那一頁用既有的 `pageAt`。預覽用疊在畫布上的 SVG（直接改 DOM，不 setState）。
  - **直線 / 箭頭**：按下 = 起點、放開 = 終點；Shift = 45° 倍數；開吸附時兩端吸附格線；移動不到 4 px = 點擊 → 預設 150 pt 的水平線。
  - **折線 / 曲線**（步驟 8、9）：每次點擊加一點，滑鼠移動時預覽下一段；雙擊或 Enter 結束、Esc 取消、Backspace 刪最後一點；少於 2 點不建立。
  - **鉛筆**（步驟 10）：按住拖曳記錄軌跡，放開時 `simplifyPoints`（容差 1.5 螢幕 px）→ `path: "smooth"` 的線；超過 500 點就加大容差再簡化。
- 建立完回到選取工具並選取新的線（同圖形）。

### 1.5 屬性面板

- `tabsOf` 線條 = 「線條」/「調整」。
- 「線條」：顏色（`ColorPicker`，可連色票）、粗細、線型（實線 / 虛線 / 點線 / 點劃線）、雙線開關（步驟 12）、起點箭頭、終點箭頭（下拉，圖示由 `linePaths` 畫）、兩端的大小（小 / 中 / 大）。
- 「調整」：圖層順序、對齊內容區、X / Y；**直線**（2 點）多「長度」「角度」。
  - 對齊內容區：六個對齊用外接框；「填滿寬度」只給水平線（角度 0° / 180°）= 內容區寬的分隔線、「填滿高度」只給垂直線，其他情況停用並說明（`fillContentDisabledReason`）。
- 右鍵選單與底部 `⋮` 共用 `element-arrange.ts`，自動跟著。

### 1.6 匯出：線條 → 虛擬圖形（Rust render 不改）

`buildExportRequest` 展開主頁 / 跨頁之後（同頁碼的做法，只在副本）：

| 虛擬圖形 | id | geometry | fill | stroke | `shapePaths` |
|---|---|---|---|---|---|
| 線本身 | 線的 id | `preset: "x-line"` | 透明 | 線的 stroke（雙線時寬度 / 3） | `outline` = `stroke` 路徑；`details` = 開放箭頭，`detailStroke` = 同色同寬實線 |
| 實心箭頭 | `<id>#heads` | `preset: "x-line-heads"` | 線的顏色 | 無 | `outline` = `fills` |

- 外框：線的外接框各邊外擴（半個線寬 + 箭頭長），寬高一定大於 0；路徑座標照舊相對於 (x, y)，旋轉照搬。
- `x-line` / `x-line-heads` 不在 `SHAPE_LIBRARY` 裡；`skippedShapeCount` 只數 `shapePaths` 沒有的 preset，不會誤報。
- EPUB 的 `svg.el` 是 `overflow: visible`（`css.rs`），箭頭超出外框不會被裁。
- Rust：`format.rs` 認得 `line`（存檔 / 開檔驗證）；`build_render` 的 `Element::Line` 不該出現在匯出請求 → `InvalidInput`「匯出資料有誤」。

### 1.7 MCP

- `add_line`：`points`（頁面座標，2–500 點）、`path`、`stroke`（顏色可連色票）、`start` / `end`（箭頭與大小）、`compound`、`pageId`。
- `update_element`：線條可改 `points`、`stroke`、`start` / `end`、`compound`、`x` / `y`；`get_element` / `list_elements` 回報線條欄位。

## 2. 步驟

每一步：程式 + 測試 + 需要時更新 `CLAUDE.md` / `docs-website/types.html` / `docs/progress.md`；做完停下來。

### 步驟 0：點劃線（`Stroke.dash` 加 `dashDot`）

- `DashPattern` 從 `{ dash, gap }` 改成**一串長度**（`segments: number[]`）：虛線 `[3w, 3w]`、點線 `[0, 2w]`（圓頭）、點劃線 `[4w, 2w, w, 2w]`（平頭，點是一小段）。
- TS：`types.ts`、`stroke.ts`（`dashPattern` / `konvaStroke` / `guideLineAttrs`）、`validation.ts`、`StrokeFields` 的選項、MCP schema（`tool-definitions.ts` → `mcp-tools.json`）。
- Rust：`format.rs` 的 `StrokeDash`、`render.rs` 的 `dash_pattern`、`pdf.rs`（`dash` 陣列）、`template.typ`、`markup.rs`（`stroke-dasharray`）。
- `SCHEMA_VERSION` 15。偏好的參考線樣式（`GuideLineStyle.dash`）**不加**點劃線（只給物件）。
- 驗收：vitest、cargo test；`export_preview` / `epub_preview` 疊圖：點劃線的矩形、橢圓、圖形庫圖形三端 ≤ 0.5 pt。

### 步驟 1：文件模型（`LineElement`）

- TS：`types.ts`、`validation.ts`（`isLineElement`）、`element-factory.ts`（`createLineElement`、`describeElement`：直線 / 箭頭 / 雙向箭頭 / 折線 / 曲線）、`geometry.localBounds`、`swatches.ts` 的 `mapColorSlots`（線的 stroke）、所有 exhaustive switch 先放最小實作（畫布暫時不畫）。
- Rust：`format.rs`（`Element::Line`、`LinePoint`、`LineEnd`、驗證）、`build_render` 的分支。
- fixture `sample.magproj`：加一條帶箭頭、連色票的折線；`docs-website/types.html`。
- 驗收：vitest + cargo test 讀同一份 fixture；`tsc` 通過。

### 步驟 2：路徑與幾何（直線、折線）

- `line-path.ts`（`linePaths`、`lineBounds`、箭頭）、`line-geometry.ts`（正規化、長度 / 角度、Shift 角度）。
- 驗收：純函式測試——尖端在端點、實心箭頭蓋住線端、虛線時頭部是實線、0 高外框、旋轉後正規化位置不動、縮短量大於線長。

### 步驟 3：畫布顯示與選取

- `LineNode` / `StaticElement`、`hitStrokeWidth`、`TRANSFORMER_OPTIONS.line`、`bakeTransform`、圖層面板 icon。
- 驗收：無頭 Edge——點選細線、框選、拖整條、多選一起拖、復原；主頁上的線、跨書背的線、頁面縮圖。

### 步驟 4：端點把手

- `line-handles.tsx`：拖端點、Shift 角度、格線吸附、一筆復原；把手不觸發框選 / 右鍵選單誤判。
- 驗收：無頭 Edge——拖端點、0° / 45° / 90°、復原；手形與建立工具下把手不作用。

### 步驟 5：線條工具（直線 / 箭頭 / 雙向箭頭）

- `ToolId.line`、`lineKind`、`L` 鍵、底部工具列按鈕與選單（圖示由 `linePaths` 畫）、`use-canvas-line.ts` 的拖曳建立、跨頁建在按下的那一頁。
- 驗收：無頭 Edge——拖曳建立、點一下建立、Shift、吸附、Esc。

### 步驟 6：屬性面板

- 「線條」分頁、「調整」分頁的長度 / 角度、對齊內容區（填滿寬度 = 分隔線）。
- 驗收：測試（`content-align` 的線條案例）＋ 無頭 Edge。

### 步驟 7：匯出

- `buildExportRequest` 展開成虛擬圖形；`skippedShapeCount` 測試。
- 驗收：`export_preview` / `epub_preview` / `flipbook_preview` 疊圖 ≤ 0.5 pt：實線 / 虛線 / 點劃線、三種箭頭、粗細 0.5 / 2 / 8 pt、旋轉、半透明、跨書背。
- **到這裡「直線 + 箭頭」整條路完成**，可以先 commit 一次（使用者決定）。

### 步驟 8：折線

- 逐點建立（雙擊 / Enter 結束、Esc、Backspace）；每個點的把手；在線段上雙擊加點、選取把手按 Delete 刪點（至少留 2 點）。
- 驗收：測試 + 無頭 Edge；疊圖加一個很尖的轉角（miter 截斷三端一致）。

### 步驟 9：曲線

- `path: "smooth"`（Catmull-Rom → 貝茲）、曲線的箭頭方向、建立方式同折線。
- 驗收：純函式測試（穿過每個點、端點切線）、疊圖（曲線上的虛線已知可能偏約 1 pt，同圖形庫）。

### 步驟 10：鉛筆

- `ToolId.pencil`、`P` 鍵、軌跡記錄、`simplifyPoints`、點數上限；鉛筆線只畫頭尾把手。
- 驗收：測試（簡化後點數、頭尾保留、上限）＋ 無頭 Edge 畫一筆、復原 ＋ 疊圖。

### 步驟 11：「繪圖」面板與分叉箭頭

- 「繪圖」面板：常用組合（分隔線、虛線、點劃線、單向 / 雙向箭頭、開放 / 實心箭頭、曲線箭頭；雙線在步驟 12 後加），點一下放到頁面中央，圖示由 `linePaths` 畫。
- 圖形庫加 `arrowSplit`「分叉箭頭」（`SHAPE_LIBRARY` 一筆，既有測試自動涵蓋）。
- 驗收：人工 + 無頭 Edge。

### 步驟 12（可選）：雙線

- `compound: "double"`（只給 straight）、屬性面板開關、「繪圖」面板的雙線。
- 驗收：測試（偏移、轉角）＋ 疊圖。

### 步驟 13：MCP 與文件

- `add_line`、`update_element` / 查詢支援線條；`npx vitest run mcp-tools -u`；`cargo build --bin magazine-mcp`；`MCP-工具清單.md`。
- `CLAUDE.md`（新的「線條」小節、目錄結構、檔案格式 v15）、`docs/progress.md`。
