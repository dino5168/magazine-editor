# 04 中文換行的避頭點（禁則）— 實作計畫

來源：`docs/progress.md` 的待辦「中文換行：Konva `word` 換行放不下時退回最後一個空白、沒有避頭點」。

## 0. 問題

畫布（和匯出，因為匯出照畫布量好的行）的換行是 Konva 10.5.0 的 `wrap: "word"`：

1. 二分搜尋放得下的最長前綴；
2. 前綴裡有空白或 `-` 就退回最後一個空白 / `-` 之後，沒有就直接在字元之間斷。

所以：

- **沒有避頭點**：「，」「。」「」」「）」可能出現在行首，「「」「（」可能出現在行尾。
- **中英混排退太多**：一行裡只要前面有一個空白（例如「使用 Konva 做畫布編輯器⋯」），放不下時就退回那個空白，後面整串中文都被推到下一行，行尾留下一大段空白。

## 1. 現況：換行只在一個地方

- 畫布的文字、圖形內文字、匯出的 `measureTextLayout` 都經 `indentAttrs()`（`src/lib/editor/indented-text.ts`）：
  - 沒有縮排：`wrap: "word"`，交給 Konva 換行。
  - 有縮排：`layoutIndentedText` 用注入的 `wrap`（`konvaWrap`，仍是 Konva 換）預先換好，節點拿 `wrap: "none"`。
- PDF / EPUB / 翻頁書 / PowerPoint 都照 `TextLayout.lines` 逐行放，自己不斷行（`export.md`）。

所以**只要換掉換行規則，三端自動一致，Rust 不用改、檔案格式不用升級**。

## 2. 設計

### 2.1 新模組 `src/lib/editor/text-wrap.ts`（純邏輯，vitest 測）

`wrapParagraph(paragraph, width, measure)` → 行陣列；`measure(text)` 由呼叫端注入（畫布用 Konva 量，和 Konva 的行寬同一個公式：`measureText` + 字數 × 字距）。

貪婪換行：

1. 剩下的文字（去掉行尾空白）放得下就整段放，結束。
2. 二分搜尋放得下的最長前綴（量的是去掉行尾空白後的寬度；至少一個字）。
3. 從前綴結尾往回找**最近的可斷點**；找不到（整串英文單字太長、或全部是禁則字元）才在放得下的位置硬斷（和 Konva 相同）。
4. 行尾空白去掉；下一行去掉行首空白（和 Konva 相同）。

「字元 i 之前可不可以斷」（`canBreakBefore`，依序判斷）：

| 條件 | 結果 |
|---|---|
| 後一個字是空白 | 可以（空白留在行尾、被去掉） |
| 後一個字是**行首禁則**字元 | 不可以 |
| 前一個字是**行尾禁則**字元 | 不可以 |
| 前一個字是空白 | 可以 |
| 前後是同一個不可分的字（`……`、`——`） | 不可以 |
| 前一個字是 `-` | 可以（Konva 原本的規則） |
| 前或後是中日韓字元（漢字、假名、全形標點、全形英數、`“”‘’…—`） | 可以 |
| 其他（英文單字、數字之間） | 不可以 |

- 行首禁則：`，。、；：？！）」』】〕〉》｝］〗〙…‥％‰℃°’”` 與半形 `,.;:!?)]}%`、日文小假名與 `ー々ゝゞヽヾ`。
- 行尾禁則：`（「『【〔〈《｛［〖〘‘“` 與半形 `([{`。
- 處理方式：**推出**（見 §3 的決定）：行首禁則字元放不下時，把它前面的字一起帶到下一行；行尾禁則字元帶到下一行。行一定不超過框寬，匯出不用處理超出的部分。

### 2.2 接上畫布（`indented-text.ts`）

- `konvaWrap` 改用 `wrapParagraph`（量字用同一個離畫面的 Konva 節點，`wrap: "none"` 時 `textArr[0].width` 就是 Konva 的行寬）。
- `indentAttrs` 沒有縮排時也**預先換好行**：`text` = 換好的行、`wrap: "none"`；對齊仍交給 Konva（`align` 與首尾置中的 `sceneFunc` 由前面的 `konvaAlignAttrs` 給），不加 `lineBoxes`（匯出的 `TextLayout` 和現在一樣沒有 `lineStarts`）。
- 和縮排一樣快取（同一個物件、文字、寬度只換一次）。
- 結果：節點的 `text` 一律 ≠ 文件原文（縮排時本來就是）；文字編輯框編輯原文，不受影響。

### 2.3 影響

- 舊文件裡「行首有標點」「中英混排」的文字會重新換行，行數可能改變（文字高度、圖形內文字的垂直置中跟著變）。匯出與畫布一起變，仍然一致。
- 純英文：和 Konva 相同（空白、`-` 處斷；單字太長時硬斷）。

## 3. 決定

- **推出（2026-10-29，使用者選定）**，不懸掛：每行都不超過框寬，匯出不用允許文字超出框外。
