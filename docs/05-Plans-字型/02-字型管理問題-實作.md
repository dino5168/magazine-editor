# 02 字型管理 — 實作計畫

需求：[02-字型管理問題.md](02-字型管理問題.md)；評估與使用者的決定：[02-字型管理問題-評估計畫.md](02-字型管理問題-評估計畫.md)（§8）。前一份：[01-專案字型-實作.md](01-專案字型-實作.md)。

## 0. 範圍（照評估 §8）

- **B 字型集合**：`.ttc` 裡的一個字型拆成單一 `.ttf` 存進專案（微軟正黑體、新細明體…）。
- **A 從系統字型加入**：列出 `%WINDIR%\Fonts` 與 `%LOCALAPPDATA%\Microsoft\Windows\Fonts` 的字型，搜尋、預覽、選家族時自動配對一般 / 粗體，加入專案。
- **C 多檔 / 拖放**：選檔對話框可以多選、可以從檔案總管拖進「字型」對話框；`.ttc` 檔要選集合裡的哪一個。
- **F 下載免費字型**：App 內建精選清單，Rust 下載、驗證 SHA-256、解壓，放進專案並留本機快取。
- **授權提醒**：翻頁書匯出時，用到非開放授權的專案字型就提醒（不阻擋）。
- **推薦字型文件**：由精選清單整理。
- 不做：App 自己的字型庫、增加內建字型、Google Fonts、安裝到 Windows、可變字型、macOS。
- **檔案格式不變**：結果都是現有的專案字型（`document.fonts` + `assets/fonts/`）。

## 1. 設計

### 1.1 字型集合 → 單一字型（Rust `project/font_collection.rs`）

```
extract_face(bytes: &[u8], index: u32) -> AppResult<Vec<u8>>
```

- 讀 `ttcf` 檔頭 → 第 `index` 個字型的表格目錄 → 依目錄把每個表格複製出來，組成標準 sfnt：檔頭（`sfntVersion` 照原字型、`searchRange` 等重算）、表格目錄（tag 排序、位移 4 位元組對齊）、表格內容；重算 `head.checkSumAdjustment`。字形資料逐位元組不變。
- **清掉簡單字形旗標的保留位元（bit 7）**：新細明體（`mingliu.ttc`）34159 個字形裡 33957 個設了這個規格保留、必須為 0 的位元，Chrome 的字型檢查（OTS）因此整個拒絕（`glyf: Bad glyph flag (151), reserved bit 7 must be set to zero`），畫布會退回替代字型。這個位元沒有作用（ttf-parser、Typst、瀏覽器都忽略），清掉不改變字形；匯入**所有** TrueType 字型（不只集合）時都做，檔案長度不變。
- **前端試載**：檔案存進專案之前，前端先用 `FontFace` 載入一次；瀏覽器拒絕（其他 OTS 錯誤）就不加入並顯示原因，避免畫布默默換成替代字型。
- 拆出來的位元組交給現有的 `analyze` / `import_font`（可變、授權、Typst 讀不讀得了照舊檢查）。存檔名照現有規則（拆出來的內容的雜湊）。
- `faces(bytes) -> Vec<FaceSummary>`：集合裡每個字型的家族 / 樣式 / 字重，給「選哪一個」用（`ttf-parser` 的 `fonts_in_collection` / `Face::parse(bytes, index)`）。

### 1.2 系統字型清單（Rust `project/system_fonts.rs` + command）

- 掃兩個資料夾的 `.ttf` / `.otf` / `.ttc`（`.fon` 等略過）。每個字型：家族（中文優先，name ID 16 → 1）、樣式、字重（`OS/2.usWeightClass`）、斜體、集合中的 index、可變、授權、有沒有中文字（`OS/2` Unicode range 與 cmap 抽查）、來源（系統 / 使用者）、不能用的原因（可變、禁止嵌入、只能點陣、讀不了）。
- **只讀需要的表格**：檔頭、表格目錄、`name`、`OS/2`、`fvar` 有無（用 seek 讀，不讀整個檔案）；結果依「路徑 + 修改時間 + 大小」快取在 App 資料夾的 `system-fonts.json`，第二次只讀變動的檔案。`spawn_blocking`。
- `system_fonts_list() -> Vec<SystemFont>`：每筆有 `id`（Rust 內部對照表的 key，不是路徑）。`font_import_system(regular: id, bold: id | null) -> ImportedFonts`：Rust 依 id 找檔案 → 必要時拆集合 → `import_font`，回傳兩個 `FontFile`（同現在匯入後的資料）。
- 家族分組與**自動配對**（前端純函式 `lib/editor/system-fonts.ts`，有測試）：同家族、不斜體；一般 = 字重最接近 400，粗體 = 字重 ≥ 600 且最接近 700（沒有就 null）。微軟正黑體：`msjh.ttc` 的「微軟正黑體」(400) + `msjhbd.ttc` 的「微軟正黑體」(700)。

### 1.3 下載免費字型（F）

- **清單** `src-tauri/fonts-catalog.json`（Rust `include_str!`，前端也讀同一份做畫面）：每套 `id`、名稱、分類（黑 / 明 / 楷 / 圓 / 手寫…）、授權（都是 SIL OFL）、官方網址、版本，以及一般 / 粗體各自的 `{ url, archivePath?, sha256, bytes }`（`archivePath` = zip 裡的檔名）。只收**靜態**字型、授權允許嵌入與再散布。
- **下載**：`font_catalog_download(id) -> ImportedFonts`：網址只來自清單；`reqwest`（rustls）下載到暫存檔 → 有 `archivePath` 就用 `zip` 解出那一個 → 驗證 SHA-256 → 存進快取 `%LOCALAPPDATA%\com.mycompany.magazineeditor\font-cache\<sha256>.<ext>` → `import_font`。快取有了就不下載。進度以 event 送前端（下載的位元組 / 總數），可以取消。
- 失敗（沒網路、網址失效、雜湊不符）→ `InvalidInput` 中文訊息，附官方網址（可以手動下載再匯入）。

### 1.4 「字型」對話框（UI）

- 現有的「匯入字型檔...」：可多選；拖放到對話框；`.ttc` 檔先問「這個檔案有 N 個字型，要用哪一個」（列出 `faces`）。
- 新增「從系統字型加入...」：清單（搜尋、只看中文、依家族分組、用系統字型名稱畫預覽、自動配對的一般 / 粗體可以改、停用原因）→ 加入草稿。
- 新增「下載免費字型...」：精選清單（名稱、分類、授權、大小、已在快取 / 已在專案）→ 下載（進度、取消）→ 加入草稿。
- 都照現有的草稿（`font-draft.ts`）：對話框「確定」才寫進文件（一筆復原）；檔案在加入時就寫進 `assets/fonts/`（同現在的匯入）。

### 1.5 授權提醒

- 開放授權 = 專案字型檔案的雜湊在**精選清單**裡（下載的）。其他（系統字型、使用者匯入的檔案）視為「請自行確認」。
- 翻頁書匯出前，文件用到這類字型時跳提醒：「〇〇字型的檔案會整個放進資料夾；放到網站前請確認授權允許散布。」可以繼續或取消（不阻擋）。PDF / EPUB 照現在的嵌入規則，不另外提醒。
