## 1. 原因分析

### Bug 1：新增頁面時排序亂掉

不是 render 的問題，是 `page/add` 的設計（`editor-reducer.ts`）：

- 新頁面**插在目前頁面的後面**（`pages.splice(activeIndex + 1, 0, page)`），不是加在最後。
- 新頁面名稱是 `Page-(max(頁數, 已用編號) + 1)`，和位置無關。

所以停在第 1 頁按「+」兩次，會得到 `封面設計, Page-5, Page-4, ...`（`bug01.png` 就是這個情形）：名稱的數字由左到右遞減，看起來像排序亂掉。

### Bug 2：頁面一多就點不到

頁籤容器是 `overflow-x-auto`，但：

- 捲軸被頁籤列的高度（`h-10`）壓住，幾乎看不到；一般滑鼠的直向滾輪不會讓它橫向捲動。
- 沒有「全部頁面清單」，也沒有左右捲動按鈕。
- 切換頁面（例如新增頁面後）不會把目前頁籤捲到看得見的位置。
- **真正的主因（步驟 2 驗證時發現）**：`home-page.tsx` 的外層 Grid 沒有指定欄寬，隱含的 `auto` 欄被頁籤列的最小內容寬度（所有 `shrink-0` 頁籤的總和）撐開。頁面一多，整個 App 比視窗還寬，頁籤區本身從來沒有溢出，所以也捲不動，右邊的頁籤直接跑到視窗外。修正：Grid 加 `grid-cols-[minmax(0,1fr)]`。

## 2. 目標畫面（參考 draw.io）

```
[+] [≡] | 第1頁  第2頁  …  [第20頁 ˅] … |  [<] [>]
```

- `+`：新增頁面。
- `≡`：所有頁面的清單（`drawio-page02.png`）：
  - 「插入頁面」
  - 分隔線
  - 每一頁一列，目前頁面打勾；點選即切換。
  - 目前頁面的那一列有子選單 ▶（重新命名 / 向左移 / 向右移 / 刪除）
  - 分隔線
  - 「頁面排序」、「全部刪除」（見第 4 節）
- 目前頁籤右側的 `˅`：同一份選單（draw.io 也是如此）。
- 右邊 `<` `>`：切換到上一頁 / 下一頁。
- 頁籤列只有頁籤這一段可以橫向捲動；直向滾輪轉成橫向捲動；切換頁面時自動把目前頁籤捲進畫面。

## 3. 不重複造輪子

- 選單用既有的 shadcn `DropdownMenu`（`components/ui/dropdown-menu.tsx`，已有 `CheckboxItem` / `Sub` / `Separator`），不自己畫浮動選單。
- 按鈕用既有的 `IconButton`；改名沿用 `InlineNameInput`；刪除確認沿用現有的 `AlertDialog`。
- 頁面的新動作（排序、全部刪除）加在 reducer（純函式 + vitest），和元素的 `element/reorder` 同一種寫法。
- 捲動到目前頁籤用 DOM 的 `scrollIntoView({ inline: "nearest" })`，不自己算位置。

## 4. 決定（2026-10-01 使用者回覆）

| # | 問題 | 決定 |
|---|---|---|
| 1 | 右邊 `<` `>` 的作用 | **切換到上一頁 / 下一頁**（和 draw.io 相同），並把頁籤捲進畫面；第一頁 / 最後一頁時對應按鈕停用 |
| 2 | 「+」新增頁面的位置 | **「+」一律加在最後**，名稱編號遞增；選單的「插入頁面」才插在目前頁面後面 |
| 3 | 「頁面排序」「全部刪除」 | **頁面排序** = 對話框，拖曳或上 / 下移調整順序，按「確定」才寫入（一次 = 一筆復原）。**全部刪除** = 先確認，刪除後留一張空白頁（沿用目前頁面的尺寸與背景，名稱 `Page-1`），可復原 |
| 4 | 目前頁面子選單 ▶ | **重新命名、向左 / 向右移動、刪除**（不做複製頁面） |

### Reducer 動作

| 動作 | 說明 |
|---|---|
| `page/add` | 加一個可省略的 `after?: PageId`：省略 = 加在最後（「+」），有值 = 插在該頁後面（「插入頁面」） |
| `page/reorder`（新） | `{ order: readonly PageId[] }`：給完整的新順序。必須剛好是現有頁面 id 的一個排列，否則 no-op；順序沒變回傳同一個 state。向左 / 向右移動與排序對話框共用 |
| `page/deleteAll`（新） | 刪除所有頁面，換成一張空白頁並選取它；新頁面的 id 由 `createPage` 產生（和 `page/add` 相同） |

### 頁面排序對話框

- 用既有的 shadcn `Dialog`；清單在對話框裡的 local state 調整，按「確定」才 dispatch `page/reorder`，「取消」/ Esc 不改文件。
- 拖曳用 HTML5 drag & drop（清單很單純，不另外加套件；`dragDropEnabled: false` 已讓 WebView2 收得到 HTML5 拖放事件），每列另有上 / 下移按鈕，鍵盤也能操作。

## 6. 100 頁以上的操作（2026-10-01 討論）

頁籤列只適合在附近前後切換，100 頁時需要其他方式。討論出的三層：

1. **頁籤列**：加頁碼輸入框（`12 / 120`，輸入數字按 Enter 跳頁）與鍵盤換頁。
2. **`≡` 選單**：頂端加搜尋框（依名稱篩選）、每列加頁碼。
3. **「頁面」工具面板**：縮圖清單、拖曳排序、多選搬移 / 刪除、右鍵選單；縮圖要快取、清單只渲染看得到的列。可以取代步驟 5 的排序對話框。

決定：

- **先做第 1 層**（步驟 3a）。第 2、3 層與步驟 4–6 之後再排。
- **跨頁（對開）之後再討論**：會影響縮圖排版，也可能影響文件模型與 EPUB 輸出。

### 步驟 3a：頁碼輸入框與鍵盤換頁

- 頁碼輸入框放在 `<` `>` 中間，顯示 `目前頁碼 / 總頁數`。Enter / 失焦才跳頁，Esc 或無效輸入還原（和 `NumberField` 同一種寫法）；超出範圍的數字夾到第一頁 / 最後一頁。
- 鍵盤：PageUp / PageDown = 上一頁 / 下一頁，Ctrl+Home / Ctrl+End = 第一頁 / 最後一頁。加在 `use-editor-shortcuts.ts`，焦點在輸入框、對話框、選單內時不觸發（沿用 `isEditableTarget`）。
- 純邏輯（解析頁碼、按鍵 → 目標頁）放在 `lib/editor/page-navigation.ts` 並補 vitest；`<` `>`、輸入框、鍵盤共用。
