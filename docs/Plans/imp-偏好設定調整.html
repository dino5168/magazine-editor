1. 任務

  1. 「偏好設定」目前是一個對話框 + 兩個分頁（Tabs）；改成用子選單拆開，每一項各自開自己的對話框。
  2. 任務單一化：一個對話框只做一件事，之後要加設定項目不必擠進同一個對話框。
  3. 紙張目前只有 A4、B5、Letter；增加更多選項（Claude 建議，使用者挑選）。

4. 擴充性的做法（不重複造輪子）

沿用「工具面板」已經用過的模式：一份清單是單一資料來源，選單指令與對話框都從它推導，缺項時編譯失敗。

// lib/preferences/settings-pages.ts（不含 UI）
export const SETTINGS_PAGES = [
  { id: "pageSetup", label: "頁面設定...",     group: "document" },
  { id: "pageNumbers", label: "頁碼管理...",   group: "document" },
  { id: "grid",      label: "格線與參考線...", group: "app", shortcut: Ctrl+, },
] as const;
export type SettingsPageId = (typeof SETTINGS_PAGES)[number]["id"];

// lib/menu/commands.ts：和 PANEL_COMMANDS 一樣由清單產生 settings.<id> 指令
// lib/menu/menu-structure.ts：子選單的項目由清單依 group 產生
// components/app/settings/index.ts：
export const SETTINGS_DIALOGS = { pageSetup: PageSetupDialog, pageNumbers: PageNumbersDialog, grid: GridDialog }
  satisfies Record<SettingsPageId, ComponentType<SettingsDialogProps>>;
  • home-page.tsx 只留一個 state：openSettings: SettingsPageId | null，handler 也由清單產生；新增一個設定頁 = 清單加一筆 + 寫一個對話框元件（漏了任一邊會編譯失敗）。
  • 共用的對話框外框（標題、說明、取消 / 確定、Esc）抽成 SettingsDialogShell，每個設定頁只寫自己的表單與「確定時做什麼」。
  • 現有表單內容直接搬：「頁面」分頁 → PageSetupDialog，「格線」分頁 → GridDialog；MmField、SwitchRow 移到共用檔。Tabs 與「記住分頁」拿掉。
  • 「頁碼管理」對話框已經獨立，只要接到清單（若採方案 A / B）。它比較寬（sm:max-w-4xl），外框要允許各頁指定寬度。

5. 紙張選項（待挑選）

單位 mm（直式）；直 / 橫仍由按鈕切換。下拉選單依系列分組顯示（shadcn SelectGroup / SelectLabel，已安裝）。

組別紙張用途建議
ISO AA3 297×420、A5 148×210、A6 105×148（A4 已有）A5：小開本雜誌、手冊；A3：海報、跨頁預覽；A6：明信片、口袋書建議
JIS BB4 257×364、B6 128×182（現有 B5 是 JIS B5，標示改成「B5（JIS）」）台灣、日本書刊常用的 B 系列建議
台灣書刊開本16 開 190×260、25 開 148×210*、32 開 130×190台灣印刷廠報價常用；*25 開和 A5 同尺寸，只列一個可選
美規Legal 215.9×355.6、Tabloid 279.4×431.8（Letter 已有）美規文件、小報可選
雜誌 / 社群正方形 210×210、美式雜誌 213×276（8⅜×10⅞ 吋）Zine、型錄、社群貼文；美國雜誌常見尺寸可選
電子書（螢幕比例）3:4（例如 150×200）、9:16（例如 112.5×200）EPUB 固定版面是本專案主力輸出，平板 / 手機比例可選
  • 現有 id（a4 / b5 / letter）不變，「範本」面板不用改；新增的用新 id。
  • 紙張清單只在前端（Rust 只驗證寬高範圍），不改檔案格式。
  • 測試：每個預設尺寸都在 10–2000 mm 內、沒有兩個尺寸相同（否則 presetIdOf 會認錯）。
使用者決定（2026-10-05）：選單用方案 A（文件 ▸ / 偏好設定 ▸，Ctrl+, 開「格線與參考線...」）。紙張加入 A3、A5、A6、B4（JIS）、B6（JIS）、16 開、32 開、Legal、Tabloid、電子書 3:4、電子書 9:16；正方形與美式雜誌不加。見第 7 節。
