頁碼管理（imp-page-settings）

任務檔：docs/Plans/2026-10-04-頁碼管理.md（不 commit）· 建立：2026-10-04 · 對應 commit：0605fe6 · 狀態：七個步驟全部完成（2026-10-04），尚未 commit；桌面版人工驗證待做

1. 任務

  1. 頁碼分奇數頁 / 偶數頁分開設定。
  2. 可以設定頁碼顯示在八個位置之一：左上、上中、右上、左中、右中、左下、下中、右下。
  3. 文字對齊：左邊的位置靠左、中間的位置置中、右邊的位置靠右；左中、右中用直式書寫。
  4. 「頁碼型態」：字型、是否加框線、頁碼顏色；套用在第 n ～ n+x 頁。
  5. 可以把文件分成多段（1～n、n+1～n+x1、…），每段各自設定。
  6. 選單「設定 → 頁面設定...」改成「設定 → 頁碼管理...」（紙張與邊界仍在「偏好設定...」的「頁面」分頁）。

2. 已和使用者確認的決定（2026-10-04）

項目決定
一段設定的結構一段 = 一個頁面範圍（第 n～m 頁），範圍內的奇數頁、偶數頁各自設定位置與前後置文字；字型、顏色、框線整段共用。範圍不可重疊
顯示的數字每段可設起始值（這段第一頁顯示的數字，預設 = 實際頁序），只用阿拉伯數字
位置基準上 / 下位置放在邊界區正中，左右對齊內容區的邊；邊界為 0（或放不下）時改用距頁緣 10 mm
直書每個字上下排（「第／1／2／頁」），沿用現有文字繪製與匯出
是否顯示只影響畫布：「顯示頁碼」是 App 偏好（和格線、邊界參考線同類，存 localStorage、不進復原、不存進專案），關掉時編輯畫面不畫頁碼，匯出照常有頁碼。預設開啟
對話框與選單「設定 → 頁面設定...」改成「頁碼管理...」；紙張與邊界仍在「偏好設定...」（Ctrl+,）；按「確定」才寫入，一次 = 一筆復原

參考圖的解讀

左：位置示意（八個位置，對齊方式由位置決定）。右：依「頁碼型態設定」參考圖整理的對話框；加了「刪除」與「確定 / 取消」。

4. 設計

4.1 資料模型（存進文件 → 專案檔，可復原）

type PageNumberPosition =
  | "topLeft" | "topCenter" | "topRight"
  | "middleLeft" | "middleRight"
  | "bottomLeft" | "bottomCenter" | "bottomRight";

/** 奇數頁或偶數頁各自的設定 */
interface PageNumberFace {
  readonly position: PageNumberPosition;
  readonly prefix: string;   // 前置文字，例如「第 」
  readonly suffix: string;   // 後置文字，例如「 頁」
}

/** 一段頁面的頁碼設定（對話框列表裡的一列） */
interface PageNumberRule {
  readonly id: string;
  readonly from: number;     // 第幾頁開始（1 起算、含）
  readonly to: number;       // 到第幾頁（含）
  readonly odd: PageNumberFace;
  readonly even: PageNumberFace;
  readonly style: Omit<TextStyle, "align"> & { readonly stroke: Stroke | null };
  readonly start: number;    // 第 from 頁顯示的數字（預設 = from），之後逐頁 +1；整數 ≥ 0
}

interface EditorDocument {
  …
  readonly pageNumberRules: readonly PageNumberRule[];   // 依 from 排序、範圍不可重疊
}
  • 奇偶依頁面在文件中的順序：第 1 頁是奇數頁。沒有被任何一段涵蓋的頁面不顯示頁碼（例如封面）。
  • 範圍不可重疊，from ≤ to；to 可以大於目前頁數（之後加頁會自動套用）。檢查放在純函式，對話框顯示錯誤、reducer 拒絕不合法的設定、Rust 讀檔時同樣驗證。
  • 新增 / 刪除 / 移動頁面時，規則跟著頁序而不是跟著某一頁（第 5 頁永遠是第 5 頁）。
  • 檔案格式：SCHEMA_VERSION 4 → 5，欄位缺少時預設空陣列，舊檔不需要升級步驟。

4.2 頁碼 → 虛擬圖形（純函式，lib/editor/page-numbers.ts）

  • findPageNumberRule(rules, pageIndex)：這一頁屬於哪一段。
  • pageNumberText(rule, pageIndex)：前置 + start + (頁序 − from) + 後置；直書位置時字與字之間加換行。
  • pageNumberShape(document, pageIndex)：回傳一個 ShapeElement（或 null），id 固定為 page-number:<pageId>；外框大小由字級與字數估算，位置見 4.3。
  • withPageNumbers(document)：把頁碼圖形加到每頁 elements 的最上層，只用在匯出前，不寫回文件。
  • 測試：奇偶、八個位置的座標與對齊、範圍外不顯示、重疊與 from > to 被判為不合法。

4.3 位置與對齊

位置水平垂直文字
左上 / 上中 / 右上靠內容區左緣 / 頁面中線 / 內容區右緣上邊界區（頁緣到上邊界線之間）的中間靠左 / 置中 / 靠右，橫書
左下 / 下中 / 右下同上下邊界區的中間同上
左中 / 右中左 / 右邊界區的中間頁面中線直書：字與字之間插入換行，外框寬 = 一個字，置中

邊界為 0（或比頁碼小）時，改用距頁緣 10 mm。頁碼可以落在邊界區，本來就不受「物件可以超出頁面」以外的限制。

4.4 畫布

  • 新的 PageNumberLayer：每頁用 pageNumberShape 產生圖形，交給既有的圖形 renderer 畫在物件上方，listening={false}。
  • 不能選取、不在圖層面板、不算進捲動範圍、不進 undo（它只是文件設定的投影）。要改頁碼只能在「頁碼管理」。
  • App 偏好 showPageNumbers 關閉時不畫這個圖層（只影響畫布，匯出不讀這個偏好）。
  • 字型：畫布等字型的清單（use-fonts-ready.ts）要包含頁碼用到的字型。

4.5 對話框（components/app/page-numbers-dialog.tsx）

  • 左邊是表單（頁碼型態 + 套用頁面 + 奇數頁 / 偶數頁），右邊是設定列表（依 from 排序）。
  • 點列表的一列 → 表單載入那一段；「加入設定」新增、「修改設定」覆寫選中的那一段、「刪除」移除。範圍重疊時顯示錯誤，按鈕停用。
  • 所有修改先在對話框內的草稿，按「確定」才 dispatch 一次 document/setPageNumbering（一筆復原、標記未存檔）；「取消」/ Esc 全部放棄；沒改動時不 dispatch。
  • 對話框最上方有「在編輯畫面顯示頁碼」開關（寫入 App 偏好，同樣按「確定」才生效；不會產生復原紀錄，也不會標記未存檔）。
  • 位置用 3×3 的按鈕格（中央空白）選，和參考圖一樣直觀；奇數頁預設右下、偶數頁預設左下（雜誌習慣：頁碼在外側）。

4.6 匯出

use-project-commands 呼叫 buildExportRequest(withPageNumbers(document), …)。頁碼變成一般圖形 + 圖形內文字，量測與 Rust 端完全沿用；PDF 與 EPUB（接上 UI 之後）都會有頁碼。Rust 的 render.rs 不用改，只有 format.rs 要認得新欄位（匯出請求裡的文件也經過同一個型別）。
