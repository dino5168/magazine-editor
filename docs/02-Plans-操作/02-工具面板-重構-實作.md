# 02 工具面板重構實作計畫

任務檔：`02-工具面板-重構.md`。本計畫依任務檔要求輸出到同一個目錄，檔名加 `-實作`。

## 1. 需求理解

1. **重設版面**（「工具面板 → 重設版面」）之後只顯示「頁面」與「屬性」兩個面板。
2. 「工具面板」選單裡的面板勾選項目**分類**，類別之間用分隔線隔開。
3. 「相片」與「素材」功能重複：把內建的範例相片搬到「素材」面板，**移除「相片」面板**。

## 2. 現況調查

| 項目 | 現況 | 位置 |

## 3. 可以沿用的東西（不重複造輪子）

## 4. 使用者決定（2026-10-14）

- ★ Q1：第一次啟動的預設**也**只有「頁面」「屬性」（預設與重設同一份）。
- ★ Q2：**A**，同類別放一組，否則依類別順序另開一組。
- ★ Q3：三類 **加入內容 ─ 屬性與樣式 ─ 頁面與圖層**，只用分隔線、不加標題。
- ★ Q4：**A**，素材面板下拉多一個「內建範例」，用到時才複製進專案、加入未分類。
- Q5（沒有另外問，照建議）：「繪圖」佔位面板這次不動，放在「加入內容」最後。

### 原本的問題與建議（留著做紀錄）

- **Q1 第一次啟動的預設版面**也改成只有「頁面」「屬性」嗎？
  （建議：**一樣**。預設與重設是同一份 `DEFAULT_DOCK_LAYOUT`，分成兩份會讓「重設」和新使用者看到的不同。已經用過的人有自己的版面記錄，不受影響，按「重設版面」才會變。）
  - 版面：左 `[頁面]`、右 `[屬性]`，兩側寬度照舊。
- **Q2 從選單打開面板時放哪裡**？現在是「加到預設側第一組的最後」，新預設下打開「文字」會變成和「頁面」同一組的頁籤。
  - A（建議）：**同類別的面板放在一起**：那一側已經有同類別面板所在的群組 → 加進那組；沒有 → **另開一組，依類別順序插入**（排在後面類別的群組之前）。依 Q3 的類別順序，左邊打開文字、元素、素材會在「頁面」上面成為同一組；右邊打開圖層會在「屬性」下面（和現在的版面一樣）。
  - B：照現在的規則（加進第一組）。最簡單，但內容面板會和頁面擠在同一組。
- **Q3 選單的分類**：
  （建議三類，選單順序如下：）
  - **加入內容**：範本、文字、元素、素材、背景、繪圖
  - **屬性與樣式**：屬性、樣式
  - **頁面與圖層**：頁面、圖層
  - 類別順序同時決定 Q2-A 新群組的上下位置（內容在頁面上面、屬性在圖層上面）。
  - 分類只用分隔線分開，不加類別標題（Radix 選單可以加 `MenubarLabel`，要的話一起做）。
- **Q4 內建相片在「素材」裡怎麼呈現**？
  - A（建議）：素材面板的資料夾下拉多一個固定項目 **「內建範例（6）」**（在「全部 / 未分類」之後、分隔線之前）。選它時顯示 6 張內建相片；點一下放到頁面中央、拖到畫布放在放下處，和其他素材一樣。**用到時才**複製進專案並加入「未分類」（沿用 `importBundled`，和現在相片面板相同）。不寫進 `library.json`，管理視窗不顯示這個項目。
  - B：建立新專案時把 6 張相片自動匯入素材庫的「範例相片」資料夾。素材庫從一開始就有東西，但每個新專案都多 6 個檔案、舊專案沒有、刪掉後要找回得重新匯入，而且要改「新增專案」流程。
- **Q5 「繪圖」面板**目前只是佔位（打開是「尚未實作」的空面板）。這次要不要從選單拿掉？
  （建議：**這次不動**，放在「加入內容」最後，保持現狀；等實作時再說。要拿掉的話是另一個小步驟。）

## 5. 設計（以建議方案寫，確認後再調整）

### 5.1 面板分類（`lib/dock/panels.ts`）
- `PanelDefinition` 加 `category: PanelCategoryId`；新增 `PANEL_CATEGORIES`（id + label，陣列順序 = 選單順序），和 `SETTINGS_GROUPS` 同一種寫法。
- `PANEL_DEFINITIONS` 依類別排序（定義順序同時是選單順序）。
- 新增 `panelsIn(category)`。

### 5.2 選單（`lib/menu/menu-structure.ts`）
- 「工具面板」= 每個類別的勾選項目，類別之間 `separator`，最後 `separator` + 重設版面。
- `menu-structure.test.ts` 加：面板指令依類別連續出現、類別之間剛好一條分隔線。

### 5.3 預設版面與打開位置（`lib/dock/dock-layout.ts`）
- `DEFAULT_DOCK_LAYOUT = { left: [group(["pages"])], right: [group(["properties"])], width: 預設 }`。
- `togglePanel` 打開時（依 Q2-A）：在預設側找「含同類別面板的第一個群組」→ 加在最後並顯示；找不到 → 新群組插在「第一個含後面類別面板的群組」之前（都沒有就放最後）。群組裡混了不同類別（使用者拖過）時，以群組裡的面板判斷，取第一個符合的。關閉照舊。
- 測試：新預設；開文字 → 頁面上方新群組；再開元素 → 同一組；開圖層 → 右邊「屬性」下面另開一組（圖層的預設側是右邊；「頁面」在左邊不算）；開樣式 → 加進「屬性」那組。

### 5.4 內建範例搬到素材面板
- 內建相片清單從 `photos-panel.tsx` 搬到新檔 `lib/library/bundled-photos.ts`（`BUNDLED_PHOTOS`：id / 名稱 / src，import 6 個 SVG）。
- `LibraryView` 不動（它是素材庫的檢視，管理視窗也用）；素材面板自己的下拉值多一個 `"samples"`，選到時顯示內建範例的格子，而不是 `visibleItems`。
- 點一下：`importBundled` → 從素材庫找到那筆（`src` 相同）→ `place(item)`；拖到畫布：同一個拖曳流程，放開時 `importBundled` → `place(item, point, pageId)`。拖曳標籤與縮圖沿用面板既有的元件。
- 「內建範例」時隱藏「匯入」區（不能匯入到內建範例），或改成匯入到未分類（建議隱藏，避免以為匯入到範例裡）。

### 5.5 移除「相片」面板
- `PANEL_DEFINITIONS` 刪 `photos`；`PANELS` / `PANEL_ICONS` 刪對應項目（`satisfies` 會提醒）；刪 `photos-panel.tsx`。
- `dock-layout.test.ts` 用到 `photos` 的地方改用其他面板 id；加一個測試：舊記錄裡有 `photos` → 讀成沒有它。
- `npx vitest run mcp-tools -u` 重產 `mcp-tools.json`（`run_command` 的列舉少 `panel.photos`）；`cargo build --bin magazine-mcp` 重編橋接程式。
- `pdf.rs` 的註解改成「素材面板的內建範例」。

## 7. 設計建議

1. **新使用者找不到內容面板**：預設只有頁面 / 屬性，「加文字」要先從選單打開「文字」面板。底部工具列已經有文字 / 圖形 / 圖片工具，所以不會卡住；但可以考慮在左側只有「頁面」時，頁籤列旁放一個「＋」按鈕（打開面板的小選單，和「工具面板」選單同一份清單）。這次不做，等用過再決定。
2. **選單的類別標題**：類別多了以後，用不能點的灰色標題（`MenubarLabel`）比只有分隔線清楚。三類時分隔線就夠。
3. **內建範例換成真的照片**：目前是 6 張 SVG 佔位圖（CSP 不允許外部圖片）。之後換成真照片時，只要改 `src/assets/photos/` 與 `bundled-photos.ts`。
4. **管理視窗也顯示內建範例**：這次只在面板（Q4-A）。若想在管理視窗挑選或整理，可以之後在左欄加一個唯讀的「內建範例」。
5. **面板 id `upload`**：「素材」面板 id 仍是 `upload`（為了舊版面記錄）。這次不改；之後若要清掉，`parseDockLayout` 可以加一個 `upload → library` 的對應。

## 8. 檢核

- **不改檔案格式、不改 Rust 程式**（只改 `pdf.rs` 一行註解）；不新增套件。
- **單一資料來源不破**：類別寫在 `PANEL_DEFINITIONS`，選單、預設側都從它推導；`PANELS` / `PANEL_ICONS` 的 `satisfies` 會擋掉漏刪 / 漏加。
- **舊資料**：
  - 舊的停靠版面含 `photos` → `parseDockLayout` 丟掉，其他面板照舊（步驟 4 測試）。
  - 舊專案裡已經用過的內建相片：已經複製進 `assets/images/`、在素材庫的未分類，不受影響。
  - 已經用過的人：版面記錄不變，按「重設版面」才變成兩個面板。
- **MCP**：`run_command` 的指令列舉會少 `panel.photos`，`mcp-tools.json` 要重產、橋接程式要重編，否則 Claude Code 看到的清單和 App 不一致（vitest 的快照測試會擋住忘了重產）。
- **風險**：
  - Q2-A 改了 `togglePanel` 的規則：既有測試要跟著改，拖放 / 關閉 / 收合等其他函式不動。
  - 內建範例「點一下」要先 `importBundled`（非同步、桌面版會寫檔）再放；連點兩下可能匯入兩次 → `importBundled` 已經用 `importOutcome` 擋重複加入，只會放兩張圖（和現在相片面板相同）。
  - 素材面板選「內建範例」時，Ctrl / Shift 選取等管理功能不適用；面板本來就沒有多選，影響小。
