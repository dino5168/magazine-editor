# 03 圖形照片（圖片框）— 實作計畫

需求：[03-圖形照片.md](03-圖形照片.md)；評估與使用者的決定：[03-圖形照片-評估計畫.md](03-圖形照片-評估計畫.md)（§6）。

## 0. 範圍（照評估的決定）

- **圖片框 = 圖形填入照片**：`ShapeElement` 多一個照片欄位；有照片時，照片裁在圖形的外形裡，底下仍畫填色（「完整顯示」時的留白處看得到），邊框、圖形內文字照常畫在上面。所有 geometry（矩形 / 四角圓角、橢圓、多邊形、星形、圖形庫 28 個）都適用。
- 入口：**素材面板拖到圖形上**、**屬性面板「照片」**、**圖片右鍵「轉成圖片框」**。不做：元素面板「圖片框」、畫布上拖曳裁切（之後另排）。
- 照片在框裡的位置：**屬性面板的數字**（填滿 / 完整顯示、水平 / 垂直對焦、縮放）。
- PDF：**先驗證**（步驟 0）。

## 1. 模型（v17）

```ts
/** A photo shown inside a shape (an image frame), clipped to the shape's outline. */
export interface ShapeImage {
  /** Same as ImageElement.src: `assets/images/<hash>.<ext>`. */
  readonly src: string;
  /** Intrinsic size in pixels (from the library item), so every end can fit it without decoding. */
  readonly imageWidth: number;
  readonly imageHeight: number;
  /** cover = fill the frame, cropping the rest (default); contain = whole photo, fill color around. */
  readonly fit: "cover" | "contain";
  /** Which part stays in view when cropping: 0 = left / top, 0.5 = center, 1 = right / bottom. */
  readonly focusX: number;
  readonly focusY: number;
  /** 1–10; enlarges the photo around the focus point. */
  readonly zoom: number;
}
// ShapeElement: readonly image: ShapeImage | null;
```

- **照片的位置只有一個公式**：`photoPlacement(width, height, image) → { x, y, width, height }`（圖形座標，可能超出外框）：cover / contain 決定基本縮放 × zoom，再依對焦把多出來的部分分到兩邊。畫布直接用；匯出由前端算好放進 `ExportRequest`（同圖形庫的 `shapePaths`，Rust 不另寫一份公式）。
- 存照片像素尺寸（從素材庫的 `ImageItem.width / height`），三端都不用為了算比例先解碼圖片。
- 檔案驗證（TS `isShapeImage` / Rust `validate_shape_image`）：`src` 過 `validate_asset_path`、像素尺寸有限且 > 0、`focus` 0–1、`zoom` 1–10、`fit` 兩種之一。舊檔缺欄位讀成 `null`（serde 預設，不需要升級步驟）。
- **檔案引用**：Rust `referenced_assets` 要算進圖形照片（**否則開檔清理會刪掉照片**）；前端 `template-content.ts` 的 `imageSources`（範本要帶走的圖片）也是。

## 2. 步驟（一次一步，每步完成後跑測試、更新進度、等使用者確認）

### 步驟 0：技術驗證（不改正式程式）

- **畫布（Konva 10.5）**：在瀏覽器模式用 scratchpad 腳本，對矩形（單一 / 四角不同圓角）、橢圓、多邊形、星形、`Path`（圖形庫）各畫一個 `fillPatternImage` + `fillPatternX / Y / Scale` + `fillPatternRepeat: "no-repeat"`，確認：照片位置和 `photoPlacement` 一致、旋轉跟著圖形、圓角裁得正確、邊框畫在照片上、命中範圍不變。
- **PDF（Typst 0.15）**：用 `export_preview` 的方式寫一個暫時的 Typst 片段：`rect` / `ellipse` / `polygon` / `curve` 的 `fill: tiling(size: ..., relative: "self", place(dx, dy, image(..)))`，算成 PNG 和畫布疊圖比對（照片位置、裁切邊緣 ≤ 0.5 pt、照片解析度沒有被點陣化變糊）。
- **EPUB**：SVG `<clipPath>`（同一條外形路徑）+ `<image x y width height preserveAspectRatio="none">`，在 Edge 疊圖比對。
- 結果寫進進度紀錄；Typst 不行時照 Q4 和使用者討論（矩形 / 圓角用 `box(clip: true, radius)`）。

### 步驟 1：模型與驗證（v17）

- TS：`types.ts`（`ShapeImage`、`ShapeElement.image`）、`validation.ts`（`isShapeImage`，`element/add` / `update` 驗證）、`createShapeElement` 等預設 `image: null`；`SCHEMA_VERSION` 在前端若有對應也一起改。
- Rust：`format.rs`（`ShapeImage`、`#[serde(default)] image: Option<ShapeImage>`、`validate_shape_image`、`SCHEMA_VERSION = 17`）、`referenced_assets`。
- 純函式 `lib/editor/shape-image.ts`：`photoPlacement`、`shapeImageFromItem(item)`（預設 cover / 0.5 / 0.5 / 1）、欄位的夾值。
- fixture `sample.magproj`：主頁 B 的六角形或封面的圓角矩形加一張照片（用已有的圖片檔）；`docs-website/types.html` 同步。
- 測試：`photoPlacement`（cover / contain、橫 / 直照片、對焦 0 / 0.5 / 1、zoom）、驗證、Rust 讀寫 / `referenced_assets` / 舊檔讀成 null。

### 步驟 2：畫布

- `ShapeBody`：有照片時，同一個外形再畫一層 pattern（底層是原本的填色）；**橢圓的 pattern 原點是圓心**（步驟 0 實測），照片位置要減掉 (width / 2, height / 2)，其他形狀直接用；`useImage(useResolveSrc()(src))`；載入前 / 讀不到時只畫填色。邊框畫在最上層（pattern 那層不帶邊框）。`StaticShape` / `StaticElement`（主頁、對頁、縮圖、範本縮圖）自動跟著。
- 照片的 Konva 屬性由 `photoPatternAttrs(placement, imagePixels)` 產生（純函式，測試）。
- 驗證：無頭 Edge 疊圖（步驟 0 的腳本改用正式程式）、雙頁、主頁、頁面縮圖。

### 步驟 3：屬性面板

- 「樣式」分頁的「填色」下面加「照片」區：
  - 沒有照片：「選擇照片...」→ Popover 列出素材庫的圖片（`LibraryThumb`，同素材面板），點一下設定（一筆復原）。
  - 有照片：縮圖＋檔名、「更換」「移除」；填滿方式（填滿 / 完整顯示）、水平 / 垂直對焦（%，`NumberField`）、縮放（%，100–1000）。
- 多選時不顯示（同其他樣式欄位）。
- 驗證：無頭 Edge（瀏覽器模式的素材是 blob URL，照片也看得到）。

### 步驟 4：操作入口

- **拖到圖形上**：`library-panel` 拖曳結束時，`locate` 回傳的頁面座標底下若是圖形（最上層、含旋轉，純函式 `shapeAtPoint(sheet, point)`；主頁內容與頁碼不算），而且拖的是圖片 → `element/update { image }`（一筆復原）並選取它；否則照舊建立圖片。拖曳中游標在圖形上時，跟著游標的標籤改成「放進圖形」。內建範例相片同樣（先 `importBundled`）。
- **圖片右鍵「轉成圖片框」**：`element-context-menu.tsx` 對單選的圖片加一項；新 reducer action `element/replace { id, element }`（同位置換成另一個物件、保留圖層順序與選取，一筆復原；測試）。新圖形 = 同位置大小與旋轉的矩形、透明填色、照片 cover / 置中（像素尺寸從素材庫找，找不到就 `loadImageSize`）。
- 驗證：無頭 Edge（拖曳、右鍵、復原）。

### 步驟 5：匯出

- `buildExportRequest`：展開主頁 / 跨頁之後，每個有照片的圖形放 `ExportRequest.shapePhotos[id] = { src, x, y, width, height }`（`photoPlacement`）。
- Rust：`render.rs` 的 `RenderElement` 多 `photo: Option<RenderPhoto>`（檔案不存在 → 略過照片、算進 `skippedImages`，同圖片）；驗證數值範圍（同 `render_path`）。
  - PDF：`template.typ` 的照片圖形畫兩次：先畫原本的填色，再畫同一個外形、`fill: tiling(size: (寬, 高), relative: "self", place(dx, dy, image(..., fit: "stretch")))`、不帶邊框，最後再畫邊框（步驟 0 實測）；`pdf.rs` 的 `drop_undrawable_svgs` 也檢查照片是 SVG 的情況。
  - EPUB / 翻頁書：`markup.rs` 有照片的圖形一律畫成 inline SVG（`<clipPath>` + `<image>`）；`collect_images` 收照片。
- 疊圖比對：PDF、EPUB 和畫布（各種形狀、旋轉、cover / contain、對焦、zoom）≤ 0.5 pt。

### 步驟 6：MCP

- `add_shape` / `update_element` 多 `image: { item, fit?, focusX?, focusY?, zoom? } | null`（`item` = 素材庫圖片的 id 或名稱，同 `place_library_item`）；`get_element` 回報照片（素材名稱、填滿方式、對焦、縮放）。
- `npx vitest run mcp-tools -u`、重編橋接程式、`MCP-工具清單.md`。

### 步驟 7：驗證與文件

- 桌面版：存檔重開（v17）、開檔清理不刪照片、文件範本帶走照片、匯出 PDF / EPUB / 翻頁書。
- `CLAUDE.md`（文件模型、檔案格式 v17、新的「圖片框」一節、兩邊同值的常數）、`docs/01`、`docs/02`、`docs-website/types.html`、進度。

## 3. 檢核

| 項目 | 結論 |
|---|---|
| 重用 | geometry / 圓角 / 換成 / 邊框 / 圖形內文字 / 對齊 / 圖層全部沿用圖形；拖曳沿用素材面板的 `startPointerDrag` + `CanvasDropProvider.locate`；照片挑選沿用 `LibraryThumb`；匯出沿用「前端算、Rust 只畫」（同 `shapePaths`）；EPUB 沿用 inline SVG 的圖形畫法 |
| 會漏的地方 | `referenced_assets`（開檔清理）、範本的 `imageSources`、`collect_images`（EPUB 收圖）、`skippedImages`：步驟 1 / 5 各自列出並有測試守著 |
| 相容性 | 檔案格式 v17（舊版 App 開新檔會說「檔案比較新」）；舊檔讀成沒有照片 |
| 已知限制（預計） | 拖到圖形上的命中判斷用外形的外框（含旋轉），不精確到星形的凹處；照片不跟著「填色」連到色票；畫布上不能直接拖照片調位置 |
| 風險 | PDF 的 `tiling`（步驟 0 先驗證）；Konva pattern 與圓角 / Path 的行為（步驟 0）；`element/replace` 是新 action（測試涵蓋復原與選取） |
