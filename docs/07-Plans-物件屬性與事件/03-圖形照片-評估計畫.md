# 03 圖形照片 — 評估計畫

需求：[03-圖形照片.md](03-圖形照片.md)（2026-10-19）。參考圖是履歷範本裡的拱形照片框（上方兩角半圓的矩形、白色細邊）。

> 這份是**評估**：方案比較、建議、要決定的事。使用者確認後才寫實作計畫（`03-圖形照片-實作.md`）。

## 1. 現況

| 物件 | 能做的 | 不能做的 |
|---|---|---|
| 圖片 `ImageElement` | `src`、位置、寬高、旋轉 | 只有長方形；沒有圓角、邊框、裁切位置 |
| 圖形 `ShapeElement` | 5 種基本 geometry ＋ 圖形庫 28 個、四角各自的圓角、填色、邊框、圖形內文字、「換成」別的圖形 | 填色只能是顏色 |

匯出：圖片 → Typst `image(..., fit: "stretch")` / EPUB `<img>`；圖形 → Typst `rect` / `ellipse` / `polygon` / `curve` 路徑、EPUB 的 inline SVG（圖形庫是前端算好的路徑）。

## 2. 方案比較

| 方案 | 做法 | 優點 | 缺點 |
|---|---|---|---|
| **A. 圖片框 = 圖形填入照片**（建議） | `ShapeElement` 多一個 `image`（照片、填滿方式、對焦位置）；有照片時用照片代替填色 | 所有形狀一次到位（圓角、橢圓、星形、圖形庫 28 個、之後新增的也是）；邊框、圖形內文字、「換成」、對齊、圖層全部沿用；和 Canva「Frames」、InDesign 圖片框的概念一致 | 圖形的畫法與三種匯出都要加「照片填色」 |
| B. 圖片加形狀遮罩 | `ImageElement` 多一個 `mask`（geometry） | 圖片仍是圖片 | 圖形已有的 geometry、圓角、邊框、換成都要在圖片上再做一次（**重複造輪子**） |
| C. 只給圖片加圓角 | `ImageElement` 多 `cornerRadius` | 最小：參考圖的拱形剛好是「上兩角半圓」 | 只有圓角矩形，橢圓、星形、多邊形都做不到 |

**建議 A**：參考圖的拱形用 A 是「圓角矩形（上兩角）＋照片＋白邊」，B / C 也做得到，但 A 同時解決所有形狀，而且幾乎所有編輯功能都是現成的。

## 3. 建議的操作方式（A）

| # | 操作 | 說明 |
|---|---|---|
| 1 | **從素材面板把照片拖到圖形上** | Canva 的做法：放下的位置在某個圖形裡 → 照片填進那個圖形（一筆復原）；放在空白處照舊建立圖片物件 |
| 2 | **屬性面板「樣式 → 填色」加「照片」** | 選擇照片（素材庫的縮圖選單）、移除照片、填滿方式、對焦位置 |
| 3 | **圖片右鍵「轉成圖片框」** | 已經放好的照片 → 變成同位置、同大小的矩形圖片框（一筆復原）；接著用屬性面板「圖形 → 換成」改成圓角 / 橢圓 / 圖形庫的形狀 |
| 4 | 元素面板「圖片框」 | 先放一個空的框（灰底＋「拖入照片」提示），再把照片拖進去；做範本時很好用（參考圖就是這種佔位框） |

**照片在框裡的位置**（建議第一版用屬性面板的數字，不做畫布上拖曳）：
- 填滿方式：**填滿**（cover，裁掉超出的部分，預設）/ **完整顯示**（contain，留白處顯示圖形的填色）。
- 對焦位置：水平 / 垂直 0–100%（cover 時決定保留哪一部分，預設 50% / 50%）；可選的「縮放」≥ 100%。
- 畫布上雙擊圖形目前是「編輯圖形內文字」，所以「雙擊進入照片裁切模式」（InDesign 的做法）會衝突，建議之後另排（例如 Alt＋拖曳移動照片）。

## 4. 技術評估

| 部分 | 做法 | 風險 |
|---|---|---|
| 模型（v17） | `ShapeElement.image: ShapeImage \| null`，`ShapeImage = { src, fit: "cover" \| "contain", focusX, focusY, zoom }`；舊檔讀成 `null`（不需要升級步驟） | 低。要改的地方都有 exhaustive 檢查：`types.ts`、`validation.ts`、Rust `format.rs`（驗證 `src` 在 `assets/images/`）、`referenced_assets`（**否則開檔清理會刪掉照片**）、fixture、`docs-website/types.html` |
| 畫布 | Konva 的 `fillPatternImage` ＋ `fillPatternScale` / `Offset`：矩形（含四個圓角）、橢圓、多邊形、Path（圖形庫）都支援；cover / contain 由外框與照片尺寸算出 scale 與 offset（純函式、可測試） | 中：需要先實測 Konva 10.5 的 pattern 在旋轉、圓角、Path 上是否正確，以及照片載入前的佔位 |
| 匯出 PDF | Typst 的 `tiling`（圖樣填色）可以當任何形狀（`rect` / `ellipse` / `polygon` / `curve`）的 `fill`，裡面放 `image` | **中高：要先做技術驗證**（tiling 的座標基準、照片解析度、疊圖比對）；不行時的備案：矩形 / 圓角用 `box(clip: true, radius)`，其他形狀先匯出成填色並提示 |
| 匯出 EPUB / 翻頁書 | inline SVG：`<clipPath>`（同一條路徑）＋ `<image preserveAspectRatio>` | 低：SVG 原生支援 |
| 圖形內文字 | 照常畫在照片上 | 無 |
| 素材 | 照片仍是素材庫的圖片；`projectAssets` 不用改（素材庫本來就有）；文件範本會自動帶走（`referenced_assets`） | 低 |
| MCP | `add_shape` / `update_element` 多 `image: { item, fit?, focusX?, focusY? } \| null`（item = 素材庫 id 或名稱，同 `place_library_item`） | 低 |

## 5. 建議的實作順序（確認後展開成實作計畫）

0. **技術驗證**：Konva pattern（各種形狀、旋轉、圓角）與 Typst `tiling` 的疊圖比對，先確定三端畫得一樣。
1. 模型 v17 與驗證（TS / Rust / fixture / `referenced_assets`）。
2. 畫布：照片填色（`cover` / `contain` / 對焦的純函式＋測試），縮圖、主頁、對頁一起。
3. 屬性面板：填色區的「照片」（選擇、移除、填滿方式、對焦位置）。
4. 操作：素材拖到圖形上、圖片右鍵「轉成圖片框」、元素面板「圖片框」。
5. 匯出：PDF、EPUB / 翻頁書，疊圖比對。
6. MCP。
7. 驗證與文件。

## 6. 使用者的決定（2026-10-19）

| # | 問題 | 決定 |
|---|---|---|
| Q1 | 方案 | **A：圖形填入照片**（圖片框） |
| Q2 | 第一版的操作入口 | **素材拖到圖形上、屬性面板選照片、圖片右鍵「轉成圖片框」**；元素面板「圖片框」不做（之後另排） |
| Q3 | 照片在框裡的位置 | **屬性面板的數字**（填滿方式、對焦位置、縮放）；畫布上拖曳裁切之後另排 |
| Q4 | PDF 的照片填色 | **先做步驟 0 驗證再決定**（不過時矩形 / 圓角用 `box(clip)`，其他形狀再討論） |

步驟 4 因此只做「素材拖到圖形上」與「轉成圖片框」。
