素材管理：操作畫面設計

依 01-素材管理可行性分析.md 的決定繪製的可操作草圖。資料只存在這個頁面裡，重新整理就會回到初始內容。

素材管理

本專案的素材庫 · 變更立即儲存

左：資料夾樹

  • 「全部」「未分類」「垃圾桶」固定在最上面，數字即時計算；資料夾的數字包含子資料夾。
  • 資料夾列滑過時出現「新增子資料夾 / 刪除」；雙擊名稱改名，同一層不可同名。
  • 拖曳資料夾：放在列的中間 = 變成它的子資料夾（框起來）；放在上緣 / 下緣 = 排在它前 / 後（插入線）；拖到「資料夾」標題 = 移到最上層。不能拖進自己的子資料夾。
  • 刪除資料夾先確認；裡面（含子資料夾）的素材移到垃圾桶，記住原資料夾。

中：素材格狀列表

  • 瀑布流依原圖比例；文字檔顯示前幾行、音訊顯示波形卡片。
  • 點選 / Ctrl+點選 / Shift+點選；Delete 移到垃圾桶；Esc 取消選取。
  • 把素材（可多選）拖到左邊的資料夾 = 移動；拖到「未分類」= 移出資料夾；拖到「垃圾桶」= 刪除。
  • 「匯入」或從檔案總管拖檔案進來：在某個資料夾裡就放進該資料夾，否則進「未分類」；同一個檔案只留一筆。

右：素材資訊

  • 預覽、名稱（可改，Enter / 失焦寫入）、種類、尺寸、檔案大小、所在資料夾、匯入日期。
  • 「放到目前頁面」= 加到頁面中央（同精簡面板的點選）；音訊沒有這個按鈕。
  • 垃圾桶裡的素材改成「還原」「永久刪除」；還原時原資料夾已不在就回到「未分類」。
  • 草圖可以真的匯入圖片 / .txt / .md / 音訊試試看（只在這個頁面裡）。

「素材」面板（取代「上傳」面板）

  • 上方選資料夾（含「全部」「未分類」），右邊按鈕開啟 A 的管理視窗。
  • 拖放區與「匯入...」：匯入到目前選的資料夾（全部時進未分類）。
  • 縮圖兩欄；點一下 = 放到頁面中央；拖到頁面 = 放在放下的位置（一筆復原）。
  • 圖片 → 圖片物件；文字檔 → 文字物件（內容原樣，.md 符號照貼）；音訊不能放到頁面。

和現有功能的關係

  • 面板 id 沿用 upload，使用者記住的停靠位置不變。
  • 舊專案的「專案圖片」開檔時成為「未分類」素材。
  • 「相片」面板的內建相片放到頁面時，也加入「未分類」。
  • 整理素材立即寫入 library.json，畫布的 Ctrl+Z 不管素材庫。
