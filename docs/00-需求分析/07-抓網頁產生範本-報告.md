# 抓網頁產生範本：報告

需求：`07-抓網頁產生範本.md`（依 FlipHTML5 線上編輯器裡的範本，透過 magazine-editor MCP 產出）。

## 結果

用 MCP 在新文件產出 12 頁的學校雜誌範本「Maplewood School Magazine」，共 238 次工具呼叫：

- **色票 10 個**：深藍 `#2d3748`、內文灰 `#575f6d`、主題藍 `#4299e1`、淺藍 `#8dc2ed`、點綴綠 / 粉 / 淡藍 / 黃、線條灰、佔位灰。
- **文字樣式 12 個**（全部連到色票）：內建的標題 / 副標題 / 內文改成範本的規格，新增封面刊名、封面副刊名、小標、目錄編號、欄目標題、圖說、標籤、提問、頁尾。
- **主頁「內頁」**：頁面標題用 `{頁面名稱}`（改頁名 = 改標題），頁尾放刊名與 `{頁碼}`；第 4–11 頁套用。
- **頁面**：封面、目錄、校長的話、8 篇專題、封底。版面（位置、大小、字級層級、配色）照範本；英文內容是重新撰寫的虛構學校，不是範本原文；圖片、影片、輪播都是灰色佔位圖形。

## 做法

1. 範本在需要登入的線上編輯器（直接抓取被擋，HTTP 403；Cloudflare 驗證由使用者完成）。用 Chrome 讀編輯器的 DOM：每個物件的外框、字型、字級、行高、字距、顏色、對齊，換算成 794 × 1123 px 的頁面座標；圖片是 `.ImgForNormal`（背景圖）、圖形是 `.baseShapeItem`。只換頁與讀取，沒有在編輯器裡修改或保存。
2. 版面規格寫成 Python 資料（px），px × 0.75 = pt（範本頁面就是 A4）。
3. 執行前用 Geist 字型（`fonts/`）量每個文字框的行數，和範本的框高比較，超出的改短。
4. 腳本以 stdio 驅動 `magazine-mcp.exe`：色票 → 樣式 → 主頁 → 頁面。

## 發現的限制

- **沒有細線**：`add_shape`（以及 App 的物件）長寬最小 4 pt（`MIN_ELEMENT_SIZE_PT`），也沒有「線條」物件。範本的 1 px 分隔線、4 px 色條都改成 4 pt 高的矩形。之後若要做線條物件或允許細矩形，另排。
- **字寬不同**：範本用 Inter，我們的黑體是 Geist，同字級寬 5–25%。封面刊名從 185 px 降到 172 px，部分標題換短字、內文縮短。照外部範本做版面時，要先用自己的字型量過。
- **圖片要使用者匯入**：MCP 不能匯入素材（設計如此），所以照片都是佔位圖形；使用者匯入後可以用 `place_library_item` 換上。
- **一次呼叫一筆復原**：238 筆遠超過復原上限 100 筆，建好之後無法一路復原回空白文件。
