# 01. 專案概觀

## 這是什麼

**雜誌編輯軟體**,Windows 桌面應用程式。使用方式類似 Canva:在頁面上加入文字、形狀、圖片,用滑鼠自由拖放排版。

**長期目標:**

- **前端編輯器:** 用 Konva.js 做拖放編輯(目前在做這部分)
- **排版與輸出:** 由 Typst 負責排版並輸出 PDF(已完成第一版)

目前是**前端編輯器 v1 + 專案存檔 / 自動備份 + 匯出 PDF**。

## 目前做得到 / 還做不到

### 做得到

| 功能 | 怎麼操作 |
|---|---|
| 加入文字 | 左側「文字」→ 標題 / 副標題 / 內文 |
| 編輯文字 | 在畫布上**雙擊**文字(支援中文輸入法選字) |
| 加入形狀 | 左側「元素」→ 矩形、圓角矩形、圓形、三角形、星形;或底部工具列的圖形工具(點一下或拖曳) |
| 圖形內文字 | 在畫布上**雙擊**圖形直接輸入(可以上 / 中 / 下對齊,超出圖形照常顯示) |
| 加入圖片 | 左側「相片」選範例圖;或「上傳」自己的圖片(PNG / JPEG / WebP / GIF,單檔 ≤ 20 MB) |
| 移動、縮放、旋轉 | 點選物件後拖曳,或拉控制點 |
| 多選、一起移動 | 按住 Ctrl 點選物件(畫布或圖層面板),或在空白處拖曳出框選取(完全包住的物件才選,按住 Ctrl 框選是加入)。選取的物件可以一起拖曳、用方向鍵移動、刪除、複製;多選時不能縮放旋轉,也不能編輯屬性 |
| 修改屬性 | 選取物件後,在右側「屬性」面板調整(參考 draw.io):樣式(填色、邊框、圓角 / 邊數 / 星形角數)、文字(字體、字級、粗體 / 斜體 / 底線 / 刪除線、對齊、顏色、陰影)、調整(位置、大小、旋轉、圖層順序) |
| 調整圖層順序 | 右側「圖層」面板,或「屬性 → 調整」的移到最上 / 最下層 |
| 頁面背景色 | 左側「背景」 |
| 紙張尺寸、邊界 | 「設定 → 偏好設定...」(Ctrl+,)的「頁面」分頁:A4 / B5 / Letter / 自訂、直式 / 橫式,套用到所有頁面(可復原,物件位置不動);邊界只在畫布上畫粉紅虛線參考線,不會輸出 |
| 格線、吸附 | 「偏好設定」的「格線」分頁:顯示格線、間距、吸附格線(拖曳、縮放、建立物件時對齊格線)、顯示邊界參考線。這些設定存在這台電腦,不存進專案 |
| 頁碼 | 「設定 → 頁碼管理...」:把文件分成幾段(第 n～m 頁),每段設定起始數字、奇數頁 / 偶數頁各自的位置(左上、上中、右上、左中、右中、左下、下中、右下;左中、右中直書)與前後置文字,以及字型、顏色、框線。頁碼畫在畫布上(不能選取,可以只在畫面上隱藏),匯出 PDF / EPUB 時一定會有 |
| 多頁 | 最下方頁籤列:新增、切換、雙擊改名、刪除 |
| 復原 / 重做 | 畫布下方的動作列,或 Ctrl+Z / Ctrl+Y(最多 100 步) |
| 縮放畫面 | 上方縮放按鈕、「符合畫面」,或 Ctrl+滾輪 |
| 其他快捷鍵 | Delete 刪除、Esc 取消選取、方向鍵微調位置 |
| 儲存 / 開啟專案 | 「檔案」選單:新增、開啟、儲存、另存新檔(Ctrl+N / O / S / Shift+S)。專案是一個資料夾,圖片會複製進去 |
| 自動備份 / 當機復原 | 有未存檔變更時每 60 秒備份一次;下次啟動會問要不要復原 |
| 匯出 PDF | 上方「匯出 PDF」按鈕,或「檔案 → 匯出為 → PDF...」。由內嵌的 Typst 排版,斷行位置和畫面一致 |

> 上面這三項只在桌面版(`npm run tauri dev`)可用。用 `npm run dev` 在瀏覽器跑時沒有檔案存取,會載入示範內容,按檔案指令會提示「僅在桌面版可用」。

### 還做不到

| 功能 | 目前狀況 |
|---|---|
| 套用範本 | 「範本」面板只是佔位,點下去只會顯示「將於後續版本提供」 |
| 自由繪圖 | 佔位面板 |
| 單頁不同尺寸、新文件的預設紙張 | 頁面設定一次改整份文件;新文件固定 A4 |
| 匯出 PNG / JPEG | 選單有項目,點了只會顯示「尚未實作」 |
| 印刷用 PDF | 匯出的是 RGB、不含出血與裁切線的閱讀 / 一般列印用 PDF |
| Dark mode 切換 | 選單有項目,但還是佔位 |

> **理解重點:** 編輯器的邏輯幾乎都在前端 (TypeScript);Rust 端負責**檔案與 PDF**——專案讀寫、圖片匯入、自動備份、Typst 排版。原則是「路徑與檔案格式由 Rust 掌握」,前端不直接碰路徑。

## 技術組成

| 層 | 使用的技術 | 它負責什麼 |
|---|---|---|
| 桌面外殼 | Tauri v2 | 把網頁包成 Windows 桌面程式 |
| 前端框架 | React 19 + TypeScript | 畫面與互動 |
| 編輯畫布 | Konva + react-konva | 在 `<canvas>` 上繪製、拖曳、縮放物件 |
| 樣式 | Tailwind CSS v4 | CSS 樣式 |
| UI 元件 | shadcn/ui | 按鈕、對話框、下拉選單等現成元件 |
| 測試 | vitest + `cargo test` | 測試編輯器的純邏輯、Rust 的檔案與匯出邏輯 |
| 後端 | Rust | 專案資料夾的讀寫、圖片匯入、自動備份 |
| PDF 排版 | Typst(以 crate 內嵌在 Rust 裡) | 把文件排版成 PDF |
| 本機資料庫 | SQLite(`rusqlite`) | 記最近開啟的專案 |

## 怎麼執行

套件管理器是 **npm**(不要用 pnpm)。

```powershell
npm install            # 第一次:安裝套件
npm run dev            # 只跑前端,在瀏覽器開啟;編輯操作完整(沒有存檔 / 匯出),最適合邊讀邊試
npm run tauri dev      # 開啟桌面程式視窗(需要 Rust)
npm test               # 執行測試
npm run build          # 型別檢查 + 打包前端
```

> **建議:** 讀文件時用 `npm run dev`,啟動快、可以直接用瀏覽器開發者工具觀察。

## 畫面和程式碼的對應

```
┌──────────────────────────────────────────────────────────────┐
│ 選單列:檔案(F)  設定(S)                                       │ ← app-menubar.tsx
├────────────┬─┬───────────────────────────────┬─┬────────────┤
│ ▾ 範本     │ │ 上方列:文件名稱、縮放、匯出    │ │ ▾ 屬性     │ ← editor-top-bar.tsx
│  (面板內容) │║├───────────────────────────────┤║│ 樣式|文字|調整│ ← properties-panel.tsx
│            │║│ 畫布                          │║│            │ ← editor-canvas.tsx
│ ▸ 文字     │ │                               │ │ ▾ 圖層     │
│   (收合)   │ │                               │ │  (面板內容) │
│            │ │  ┌↶ ↷ 🗑 ⧉ ⋮┐                 │ │            │ ← 動作列
│            │ │  │▶ ✋ T □ 🖼 ^│               │ │            │ ← bottom-toolbar.tsx
├────────────┴─┴───────────────────────────────┴─┴────────────┤
│ 頁籤列:Page-1  Page-2  +                                      │ ← editor-page-bar.tsx
└──────────────────────────────────────────────────────────────┘
  ↑ 左停靠區        ↑ 分隔條(拖曳調整寬度)            右停靠區 ↑
  dock-area.tsx     dock-splitter.tsx
```

- 畫布下方是**底部工具列**(參考 tldraw):先選工具(選取 V、手形 H、文字 T、圖形 R / O),再到畫布上點擊或拖曳建立,建立完回到選取工具;按住空白鍵拖曳可以平移畫面。上面的小列是動作列:復原、重做、刪除、複製(Ctrl+D)、⋮(圖層順序)。
- 右側最上方的「屬性」面板(參考 draw.io)顯示目前選取物件的屬性,分成樣式 / 文字 / 調整三頁;沒有選取時顯示操作提示。
- 左右兩側是**工具面板**(參考 Krita):從「設定 → 工具面板」勾選要顯示哪些,拖曳標題列可以換到另一側或調整順序,點標題列可以收合。面板內容在 `src/components/editor/panels/*.tsx`,外框在 `src/components/dock/`。版面會記住,重開 App 後還原。

整個版面組合在 `src/pages/home-page.tsx`。`app-menubar.tsx` 在 `src/components/app/`,工具面板的外框在 `src/components/dock/`,其餘都在 `src/components/editor/`。

## 自我檢查題

1. 在目前版本畫好一頁、關閉 App 再打開,內容還在嗎?分成用 `npm run dev` 和 `npm run tauri dev` 兩種情況回答。
2. 「匯出 PDF」和「套用範本」現在能用嗎?
3. Rust 後端目前在編輯器裡扮演什麼角色?
4. 想邊看程式碼邊試功能,應該用哪個指令啟動?有什麼限制?

<details>
<summary>參考答案</summary>

1. **桌面版(`npm run tauri dev`)在。** 存過檔的專案下次啟動會自動開啟;就算沒存檔,自動備份也會問你要不要復原。**瀏覽器(`npm run dev`)不在**:沒有檔案存取,每次都載入示範內容。
2. **匯出 PDF 可以**(桌面版),由內嵌的 Typst 排版,斷行位置和畫面一致。**套用範本還不行**,範本面板只是佔位,點了只會顯示提示。
3. **負責檔案與 PDF。** 專案資料夾的讀寫、圖片匯入、自動備份、Typst 排版都在 Rust 端,另外還有一個 SQLite 資料庫(記最近開啟的專案)。設計原則是**路徑與檔案格式由 Rust 掌握**,前端不直接碰路徑。
4. `npm run dev`:只跑前端,啟動快,編輯器操作完整。限制是沒有 Tauri IPC,所以存檔 / 開啟 / 匯出 PDF 都不能用(會提示「僅在桌面版可用」),圖片改用 `blob:` URL。

</details>
