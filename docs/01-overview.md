# 01. 專案概觀

## 這是什麼

**雜誌編輯軟體**,Windows 桌面應用程式。使用方式類似 Canva:在頁面上加入文字、形狀、圖片,用滑鼠自由拖放排版。

**長期目標:**

- **前端編輯器:** 用 Konva.js 做拖放編輯(目前在做這部分)
- **排版與輸出:** 由 Typst 負責排版並輸出 PDF(尚未開始)

目前是**前端編輯器 v1**。

---

## 目前做得到 / 還做不到

### 做得到

| 功能 | 怎麼操作 |
|---|---|
| 加入文字 | 左側「文字」→ 標題 / 副標題 / 內文 |
| 編輯文字 | 在畫布上**雙擊**文字(支援中文輸入法選字) |
| 加入形狀 | 左側「元素」→ 矩形、圓角矩形、圓形、三角形、星形 |
| 加入圖片 | 左側「相片」選範例圖;或「上傳」自己的圖片(PNG / JPEG / WebP / GIF,單檔 ≤ 20 MB) |
| 移動、縮放、旋轉 | 點選物件後拖曳,或拉控制點 |
| 修改屬性 | 選取物件後,用畫布上方的屬性工具列調整 |
| 調整圖層順序 | 左側「圖層」 |
| 頁面背景色 | 左側「背景」 |
| 多頁 | 最下方頁籤列:新增、切換、雙擊改名、刪除 |
| 復原 / 重做 | 上方按鈕,或 Ctrl+Z / Ctrl+Y(最多 100 步) |
| 縮放畫面 | 上方縮放按鈕、「符合畫面」,或 Ctrl+滾輪 |
| 其他快捷鍵 | Delete 刪除、Esc 取消選取、方向鍵微調位置 |

### 還做不到

| 功能 | 目前狀況 |
|---|---|
| **儲存 / 開啟文件** | **沒有**。文件只存在記憶體,關閉 App 就消失;每次啟動都載入示範內容 |
| 匯出 PDF | 按鈕是停用狀態,等待 Typst 整合 |
| 套用範本 | 「範本」面板只是佔位,點下去只會顯示「將於後續版本提供」 |
| 自由繪圖 | 佔位面板 |
| 變更頁面尺寸 | 「尺寸」面板只顯示目前尺寸 |
| Rust 後端 | 已經有 SQLite 資料庫和 3 個指令,但**前端還沒有使用** |

> **理解重點:** 目前幾乎所有邏輯都在前端 (TypeScript)。Rust 端只是預先準備好的骨架。

## 技術組成

| 層 | 使用的技術 | 它負責什麼 |
|---|---|---|
| 桌面外殼 | Tauri v2 | 把網頁包成 Windows 桌面程式 |
| 前端框架 | React 19 + TypeScript | 畫面與互動 |
| 編輯畫布 | Konva + react-konva | 在 `<canvas>` 上繪製、拖曳、縮放物件 |
| 樣式 | Tailwind CSS v4 | CSS 樣式 |
| UI 元件 | shadcn/ui | 按鈕、對話框、下拉選單等現成元件 |
| 測試 | vitest | 測試編輯器的純邏輯 |
| 後端 | Rust + SQLite | 本機資料庫(目前未使用) |

## 怎麼執行

套件管理器是 **npm**(不要用 pnpm)。

```powershell
npm install            # 第一次:安裝套件
npm run dev            # 只跑前端,在瀏覽器開啟;編輯器功能完整,最適合邊讀邊試
npm run tauri dev      # 開啟桌面程式視窗(需要 Rust)
npm test               # 執行測試
npm run build          # 型別檢查 + 打包前端
```

> **建議:** 讀文件時用 `npm run dev`,啟動快、可以直接用瀏覽器開發者工具觀察。

## 自我檢查題

1. 在目前版本畫好一頁、關閉 App 再打開,內容還在嗎?為什麼?
2. 「匯出 PDF」和「套用範本」現在能用嗎?
3. Rust 後端目前在編輯器裡扮演什麼角色?
4. 想邊看程式碼邊試功能,應該用哪個指令啟動?

<details>
<summary>參考答案</summary>

1. **不在。** 目前沒有持久化(儲存)功能,文件只存在記憶體;每次啟動都會載入示範內容。
2. **都不能。** 匯出 PDF 按鈕是停用的(等 Typst 整合);範本面板只是佔位,點了只會顯示提示。
3. **幾乎沒有。** Rust 端已經準備好 SQLite 和 3 個指令,但前端還沒有呼叫它們。
4. `npm run dev`:只跑前端,啟動快,編輯器功能完整。

</details>
